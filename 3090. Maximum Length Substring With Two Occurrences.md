# Sliding Window O(n) | Python | Hash Map

## Intuition

We need to find the longest substring in which **every character appears at most twice**.

A brute-force solution would generate every substring and count its characters, but that is inefficient.

Instead, we can use a **sliding window**.

We maintain a window from index `i` to `j` and store the frequency of every character inside the window.

When adding `s[j]` causes its frequency to become greater than `2`, the current window is invalid. We then move the left pointer `i` forward until the frequency becomes valid again.

This allows us to find the longest valid substring efficiently.

---

## Approach

1. Initialize:

   * `i = 0` as the left pointer.
   * `ans = 0` to store the maximum length.
   * `c` as a frequency dictionary.
2. Traverse the string using `j`.
3. Increment the frequency of the current character:

   ```python
   c[x] += 1
   ```
4. If the frequency of the current character becomes greater than `2`, shrink the window from the left:

   ```python
   while c[x] > 2:
       c[s[i]] -= 1
       i += 1
   ```
5. Once the window is valid, calculate its length:

   ```python
   j - i + 1
   ```
6. Update the maximum length.
7. Return `ans`.

The key idea is that the window always contains a substring where every character occurs at most twice.

---

## Example

Consider:

```text
s = "bcbbbcba"
```

We expand the window from left to right.

When a character occurs for the third time, we move the left pointer forward until that character appears at most twice.

For example, when the window contains:

```text
"bcbbb"
```

`b` appears three times, so the window is invalid.

We remove characters from the left until:

```text
"bbb"
```

becomes valid with `b` appearing twice or fewer.

The window continuously adjusts itself while we scan the string.

---

## Complexity

* Time complexity:

$$O(n)$$

Each character is added to the window once and removed from the window at most once.

Therefore, both pointers together move at most `2n` times.

* Space complexity:

$$O(n)$$

The frequency dictionary stores the characters present in the current window.

For a fixed lowercase alphabet, this can effectively be considered:

$$O(1)$$

---

## Code

```python
from collections import defaultdict

class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        n = len(s)
        ans = 0
        i = 0
        c = defaultdict(int)

        for j, x in enumerate(s):
            c[x] += 1

            while c[x] > 2:
                c[s[i]] -= 1
                i += 1

            ans = max(ans, j - i + 1)

        return ans
```

## Why the Sliding Window Works

The important condition is:

```text
Every character appears at most twice
```

Whenever this condition is violated, only the left side of the window needs to be removed.

Because the window was valid before adding `s[j]`, the only character that can cause the violation is the newly added character.

Therefore, we can shrink the window specifically while:

```python
c[x] > 2
```

Once the condition becomes valid again, we know the current window is a valid candidate.

---

## Comparison With Brute Force

Your first solution repeatedly creates a `Counter` for every possible substring:

```python
for i in range(len(s)):
    for j in range(i + 1, len(s)):
        counts = Counter(s[i:j + 1])
```

This results in much higher time complexity.

The second solution improves this using a sliding window:

```text
Brute Force → repeated substring + Counter
Sliding Window → maintain frequency while moving pointers
```

The sliding-window solution runs in **O(n)** time.

---

## Key Takeaways

* Use a frequency map to track characters inside the current window.
* Expand the right pointer one character at a time.
* If any character appears more than twice, move the left pointer.
* Keep track of the maximum valid window.
* This converts the brute-force approach into an efficient sliding-window solution.
