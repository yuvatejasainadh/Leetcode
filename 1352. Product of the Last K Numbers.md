# Prefix Product | Python | Array

## Intuition

We need to support two operations:

* Add a number to the sequence.
* Find the product of the last `k` numbers.

Calculating the product of the last `k` elements every time would be expensive.

Instead, we maintain a **prefix product array**.

For example, if we add:

```text
3, 2, 5
```

we store:

```text
[1, 3, 6, 30]
```

Here:

* `3` → `3`
* `3 × 2` → `6`
* `3 × 2 × 5` → `30`

The product of the last `k` numbers can then be obtained using division.

---

## Approach

### 1. Initialize the Prefix Product

We start with:

```python
self.nums = [1]
```

The initial `1` acts as a neutral value for multiplication.

---

### 2. Adding a Number

If `num` is not zero, append the new prefix product:

```python
self.nums.append(self.nums[-1] * num)
```

For example:

```text
Add 3 → [1, 3]
Add 2 → [1, 3, 6]
Add 5 → [1, 3, 6, 30]
```

### Handling Zero

A zero makes the product of any sequence containing it equal to zero.

Therefore, when `0` is added, we reset:

```python
self.nums = [1]
```

This effectively starts a new sequence after the zero.

---

### 3. Getting the Product

Suppose:

```text
nums = [1, 3, 6, 30, 120]
```

and we want the product of the last `2` numbers:

```text
5 × 4 = 20
```

The prefix products are:

```text
1, 3, 6, 30, 120
```

So:

```text
120 / 6 = 20
```

In the code:

```python
self.nums[-1] // self.nums[-1-k]
```

If `k` is larger than the number of available elements after the most recent zero, the result must be `0`:

```python
if k >= len(self.nums):
    return 0
```

---

## Example

Consider:

```text
add(3)
add(2)
add(5)
```

Prefix products:

```text
[1, 3, 6, 30]
```

Now:

```text
getProduct(2)
```

The last two numbers are:

```text
2 × 5 = 10
```

Using prefix products:

```text
30 / 3 = 10
```

Therefore:

```text
Output = 10
```

## Complexity

* Time complexity:

**`add()`**

$$O(1)$$

**`getProduct()`**

$$O(1)$$

Both operations use only a constant number of operations.

* Space complexity:

$$O(n)$$

The prefix product array stores information for the numbers added since the most recent zero.

---

## Code

```python
class ProductOfNumbers:

    def __init__(self):
        self.nums = [1]

    def add(self, num: int) -> None:
        if num == 0:
            self.nums = [1]
        else:
            self.nums.append(self.nums[-1] * num)

    def getProduct(self, k: int) -> int:
        return 0 if k >= len(self.nums) else self.nums[-1] // self.nums[-1 - k]
```

---

## Key Takeaways

* Prefix products allow product queries to be answered in constant time.
* Division of two prefix products gives the product of a subarray.
* A zero requires resetting the prefix product array.
* The initial `1` simplifies prefix-product calculations.
* Both `add()` and `getProduct()` run in **O(1)** time.
