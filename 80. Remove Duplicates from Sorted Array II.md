# Simple O(n²) | Python | Sorting

## Intuition

Since the array is already sorted, duplicate values appear next to each other.

The goal is to make sure that every value appears **at most twice**.

The approach is to count how many times each value occurs using:

```python
nums.count(nums[i])
```

If a value occurs more than twice, we replace the current occurrence with `30001`.

`30001` is used because the problem constraints ensure that valid values are smaller than this number. Therefore, these replaced values can safely be moved to the end when we sort the array.

For example:

```text
nums = [1, 1, 1, 2, 2, 3]
```

There are three `1`s, so one of them is replaced:

```text
[1, 1, 30001, 2, 2, 3]
```

After sorting:

```text
[1, 1, 2, 2, 3, 30001]
```

The valid portion contains:

```text
[1, 1, 2, 2, 3]
```

So the answer is `5`.

---

## Approach

1. Store the initial length of the array in `cnt`.
2. Traverse every element of `nums`.
3. Count the occurrences of the current value using:

   ```python
   nums.count(nums[i])
   ```
4. If the value occurs more than twice:

   * Replace the current element with `30001`.
   * Decrease `cnt`.
5. After processing all elements, sort the array.
6. The replaced `30001` values move to the end of the array.
7. Return `cnt`, which represents the number of valid elements.

### Why `30001`?

The problem guarantees that the numbers in `nums` are within the range:

```text
-10^4 <= nums[i] <= 10^4
```

Therefore, `30001` is larger than every valid input value.

After sorting, all replaced elements move to the end.

---

## Example

Consider:

```text
nums = [0, 0, 1, 1, 1, 1, 2, 3, 3]
```

The value `1` occurs four times.

The extra occurrences are replaced with `30001`:

```text
[0, 0, 1, 1, 30001, 30001, 2, 3, 3]
```

After sorting:

```text
[0, 0, 1, 1, 2, 3, 3, 30001, 30001]
```

There are `7` valid elements:

```text
[0, 0, 1, 1, 2, 3, 3]
```

Therefore:

```text
Output = 7
```

---

## Complexity

* Time complexity:

$$O(n^2 + n\log n)$$

For every element, `nums.count()` scans the entire array, resulting in:

$$O(n^2)$$

After that, `nums.sort()` takes:

$$O(n\log n)$$

Therefore, the total complexity is:

$$O(n^2 + n\log n) = O(n^2)$$

* Space complexity:

$$O(1)$$

The solution modifies the input array in-place and does not use an additional data structure proportional to the input size.

---

## Code

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        cnt = len(nums)

        for i in range(len(nums)):
            if nums.count(nums[i]) > 2:
                nums[i] = 30001
                cnt -= 1

        nums.sort()

        return cnt
```

## Dry Run

### Input

```text
nums = [1, 1, 1, 2, 2, 3]
```

### Step 1: Count Occurrences

For `1`:

```text
count(1) = 3
```

Since it occurs more than twice, replace one occurrence:

```text
[1, 1, 30001, 2, 2, 3]
```

`cnt` becomes:

```text
5
```

The other values occur at most twice, so they remain unchanged.

### Step 2: Sort

```text
[1, 1, 2, 2, 3, 30001]
```

### Step 3: Return Count

```text
5
```

The first five elements are:

```text
[1, 1, 2, 2, 3]
```

---

## Key Takeaways

* `nums.count()` can determine how many times a value occurs.
* Values occurring more than twice are replaced with a number outside the input range.
* Sorting moves these placeholder values to the end.
* `cnt` tracks the number of valid elements.
* The solution modifies `nums` in-place.
* Although simple, this approach is `O(n²)` because of repeated `count()` operations.
* A two-pointer approach can solve the problem in `O(n)` time without sorting.
