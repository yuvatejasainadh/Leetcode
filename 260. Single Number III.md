# Simple O(n²) | Python | Array

## Intuition

Every number in the array appears exactly twice except for two numbers that appear only once.

The simplest way to identify those two unique numbers is to count how many times each number appears.

For every number in `nums`, we check:

```python
nums.count(i)
```

If its count is exactly `1`, then it is one of the two unique numbers, so we add it to the answer.

For example:

```text
nums = [1, 2, 1, 3, 2, 5]
```

The frequencies are:

```text
1 → 2 times
2 → 2 times
3 → 1 time
5 → 1 time
```

Therefore, the two numbers that appear once are:

```text
[3, 5]
```

---

## Approach

1. Initialize an empty list `ans`.
2. Traverse every element in `nums`.
3. For each element, use `nums.count(i)` to determine its frequency.
4. If the frequency is exactly `1`, add the number to `ans`.
5. Return `ans`.

### Example

For:

```text
nums = [1, 2, 1, 3, 2, 5]
```

The iteration checks:

```text
1 → count = 2 → ignore
2 → count = 2 → ignore
1 → count = 2 → ignore
3 → count = 1 → add 3
2 → count = 2 → ignore
5 → count = 1 → add 5
```

Final result:

```text
[3, 5]
```

---

## Complexity

* Time complexity:

$$O(n^2)$$

The loop iterates through all `n` elements.

For every element, `nums.count(i)` takes `O(n)` time because it scans the entire list.

Therefore:

$$O(n) \times O(n) = O(n^2)$$

* Space complexity:

$$O(1)$$

Apart from the output list, the algorithm uses only constant extra space.

If the output list is included, it contains exactly two elements, so it is still:

$$O(1)$$

---

## Code

```python
class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        ans = []

        for i in nums:
            if nums.count(i) == 1:
                ans.append(i)

        return ans
```

---

## Key Takeaways

* The array contains exactly two numbers that appear once.
* All other numbers appear exactly twice.
* `nums.count(i)` can be used to find the frequency of each number.
* If the frequency is `1`, the number is one of the required answers.
* This solution is simple but has `O(n²)` time complexity because `count()` scans the entire array for every element.
