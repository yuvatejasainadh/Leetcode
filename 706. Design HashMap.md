# Simple O(n) | Python | Array

## Intuition

A HashMap stores data as **key-value pairs**.

For every key, we need to support three operations:

* `put(key, value)` → add or update a key-value pair.
* `get(key)` → return the value associated with the key.
* `remove(key)` → delete the key-value pair.

This implementation uses two lists:

* `self.s` stores the keys.
* `self.c` stores the corresponding values.

The same index in both lists represents one key-value pair.

For example:

```text
s = [1, 5, 10]
c = [20, 50, 100]
```

represents:

```text
1  → 20
5  → 50
10 → 100
```

---

## Approach

### `__init__()`

Initialize two empty lists:

```python
self.s = []
self.c = []
```

`self.s` stores keys, while `self.c` stores their corresponding values.

### `put(key, value)`

First check whether the key already exists.

If it exists, find its index and update the corresponding value:

```python
self.c[self.s.index(key)] = value
```

Otherwise, append the key and value:

```python
self.s.append(key)
self.c.append(value)
```

### `get(key)`

If the key exists, find its index and return the corresponding value:

```python
self.c[self.s.index(key)]
```

If the key doesn't exist, return:

```text
-1
```

### `remove(key)`

If the key exists:

1. Find its index.
2. Remove the value at that index.
3. Remove the key.

This keeps both lists synchronized.

## Complexity

* Time complexity:

$$O(n)$$

Operations such as `in`, `.index()`, `.pop()`, and `.remove()` may require scanning the lists.

Here, `n` is the number of stored key-value pairs.

* Space complexity:

$$O(n)$$

The keys and their corresponding values are stored in two lists.

## Code

```python
class MyHashMap:

    def __init__(self):
        self.s = []
        self.c = []

    def put(self, key: int, value: int) -> None:
        if key in self.s:
            self.c[self.s.index(key)] = value
        else:
            self.s.append(key)
            self.c.append(value)

    def get(self, key: int) -> int:
        if key in self.s:
            return self.c[self.s.index(key)]
        return -1

    def remove(self, key: int) -> None:
        if key in self.s:
            self.c.pop(self.s.index(key))
            self.s.remove(key)

```

## Key Takeaways

* A HashMap stores **keys and their corresponding values**.
* Two lists can be used to maintain the key-value relationship.
* The same index in both lists represents one mapping.
* Existing keys are updated rather than duplicated.
* Missing keys return `-1`.
* This implementation has `O(n)` operations because it uses linear list searching.
