# Simple O(m × n × k) | Python | Matrix

## Intuition

The main idea is to first find all the rows and columns that contain a `0`.

We cannot immediately set an entire row or column to zero while traversing the matrix because doing so could create **new zeros** that were not present in the original matrix.

For example:

```text
1  1  1
1  0  1
1  1  1
```

The `0` means that the second row and second column must become zero:

```text
1  0  1
0  0  0
1  0  1
```

Therefore, we first store the indices of all rows and columns containing zero.

The lists:

```python
idxi
idxj
```

store the row and column indices respectively.

After finding all zero positions, we traverse the entire matrix again and set an element to `0` if:

```python
i in idxi or j in idxj
```

---

## Approach

### Step 1: Find Zero Positions

Traverse every element of the matrix.

Whenever we find:

```python
matrix[i][j] == 0
```

we store:

```python
idxi.append(i)
idxj.append(j)
```

Here:

* `idxi` contains the rows that need to be zeroed.
* `idxj` contains the columns that need to be zeroed.

### Step 2: Set Required Cells to Zero

After identifying all affected rows and columns, call:

```python
self.setZero(matrix, idxi, idxj)
```

Inside `setZero()`, traverse the entire matrix again.

For every position `(i, j)`:

```python
if i in a or j in b:
    m[i][j] = 0
```

If the row or column was identified earlier, set that cell to zero.

### Example

Consider:

```text
1  1  1
1  0  1
1  1  1
```

First pass finds:

```text
idxi = [1]
idxj = [1]
```

Then every cell in row `1` or column `1` is set to zero:

```text
1  0  1
0  0  0
1  0  1
```

---

## Complexity

Let:

* `m` = number of rows

* `n` = number of columns

* `k` = number of stored zero rows/columns

* Time complexity:

$$O(m \times n \times k)$$

The matrix is traversed once to find zeros.

Then it is traversed again, and for every cell we perform:

```python
i in idxi
```

or:

```python
j in idxj
```

List membership takes `O(k)` time in the worst case.

Therefore, the overall complexity is:

$$O(mn \times k)$$

In the worst case, this can become:

$$O((mn)^2)$$

* Space complexity:

$$O(m + n)$$

The `idxi` and `idxj` lists store the affected row and column indices.

---

## Code

```python
class Solution:
    def setZero(self, m, a, b):
        for i in range(len(m)):
            for j in range(len(m[0])):
                if i in a or j in b:
                    m[i][j] = 0

    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """

        idxi = []
        idxj = []

        for i in range(len(matrix)):
            for j in range(len(matrix[0])):
                if matrix[i][j] == 0:
                    idxi.append(i)
                    idxj.append(j)

        self.setZero(matrix, idxi, idxj)
```

## Dry Run

Consider:

```text
matrix =
[
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1]
]
```

### First Pass

We find:

```text
matrix[1][1] = 0
```

Therefore:

```text
idxi = [1]
idxj = [1]
```

### Second Pass

Check every cell.

For row `1`:

```text
1  0  1
```

All elements become zero.

For column `1`:

```text
0
0
0
```

All elements become zero.

Final matrix:

```text
1  0  1
0  0  0
1  0  1
```

---

## Important Observation

The reason we use two passes is to avoid accidentally treating newly created zeros as original zeros.

Suppose we immediately zeroed rows and columns whenever we encountered a zero. Those newly created zeros could cause additional rows and columns to be incorrectly modified.

By storing the original zero positions first, we avoid this problem.

---

## Key Takeaways

* First identify all rows and columns containing an original `0`.
* Store row indices in `idxi`.
* Store column indices in `idxj`.
* Only after finding all zeros, modify the matrix.
* The matrix is modified **in-place**.
* Using Python lists for membership makes the implementation slower than a set-based approach.
* The optimal solution can achieve `O(mn)` time and `O(1)` extra space, but this implementation does not use that optimization.
