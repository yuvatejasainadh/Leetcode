# Simple O(n) | MySQL | Self Join

## Intuition

We need to find employees whose salary is **greater than their manager's salary**.

Each employee has a `managerId` that refers to another employee's `id` in the same `employee` table.

So, for every employee, we can look up their manager's salary using a subquery and compare the two salaries.

---

## Approach

1. Select the employee's name:

   ```sql
   e.name AS Employee
   ```
2. For each employee, find the salary of their manager:

   ```sql
   SELECT m.salary
   FROM employee m
   WHERE m.id = e.managerId
   ```
3. Compare the employee's salary with the manager's salary:

   ```sql
   e.salary > manager_salary
   ```
4. Return the names of employees satisfying the condition.

The subquery is correlated with the outer query through:

```sql
m.id = e.managerId
```

---

## Example

Suppose the table contains:

| id | name  | salary | managerId |
| -: | ----- | -----: | --------: |
|  1 | Joe   |  70000 |         3 |
|  2 | Henry |  80000 |         4 |
|  3 | Sam   |  60000 |      NULL |
|  4 | Max   |  90000 |      NULL |

For Joe:

```text
Joe's salary = 70000
Manager's salary = 60000
```

Since:

```text
70000 > 60000
```

Joe is included in the result.

For Henry:

```text
80000 < 90000
```

so Henry is not included.

---

## Complexity

* Time complexity:

$$O(n)$$

The query checks employees against their corresponding managers. The exact database execution cost can depend on indexes and the query optimizer.

* Space complexity:

$$O(1)$$

Apart from internal database processing, the query does not explicitly create an additional data structure.

---

## Code

```mysql
# Write your MySQL query statement below

SELECT 
    e.name AS Employee
FROM employee e
WHERE e.salary > (
    SELECT m.salary
    FROM employee m
    WHERE m.id = e.managerId
);
```

---

## Key Takeaways

* The `employee` table is referenced twice.
* The outer query represents the employee.
* The subquery represents the employee's manager.
* `managerId` connects an employee to their manager.
* The salary comparison is performed directly in the `WHERE` clause.

---

## Alternative Approach

The same problem can also be solved using a **self JOIN**, which is often easier to read:

```mysql
SELECT e.name AS Employee
FROM employee e
JOIN employee m
    ON e.managerId = m.id
WHERE e.salary > m.salary;
```

Here:

* `e` → employee
* `m` → manager

Both references point to the same `employee` table.
