# Simple O(n) | Python | String Split

## Intuition

The goal is to split every string in `words` using the given `separator`.

Python provides the built-in `split()` method, which makes this straightforward.

For example:

```text
words = ["one.two", "three.four"]
separator = "."
```

Splitting each word gives:

```text
["one", "two"]
["three", "four"]
```

We then combine all the resulting strings into one list.

One important detail is that consecutive separators can create empty strings. These empty strings should not be included in the answer, so they are removed before adding the result.

---

## Approach

1. Initialize an empty list `ans`.
2. Traverse every string `x` in `words`.
3. Split the string using:

   ```python
   x.split(separator)
   ```
4. Remove all empty strings from the resulting list.
5. Add the remaining strings to `ans`.
6. Return `ans`.

For example:

```text
words = ["one.two..three"]
separator = "."
```

After splitting:

```text
["one", "two", "", "three"]
```

After removing the empty string:

```text
["one", "two", "three"]
```

---

## Complexity

* Time complexity:

$$O(n)$$

where `n` is the total number of characters across all strings.

The strings need to be traversed to perform the splits and construct the result.

> Note: The `while "" in y` loop can repeatedly scan the list, so the exact implementation can have additional overhead when there are many empty strings. Under the problem constraints, the overall processing remains efficient.

* Space complexity:

$$O(n)$$

The split results and the final answer require space proportional to the total number of characters/words produced.

---

## Code

```python
class Solution:
    def splitWordsBySeparator(self, words: List[str], separator: str) -> List[str]:
        ans = []

        for x in words:
            y = x.split(separator)

            while "" in y:
                y.remove("")

            ans += y

        return ans
```

## Dry Run

Consider:

```text
words = ["one.two..three", "four.five"]
separator = "."
```

### First Word

```text
"one.two..three".split(".")
```

gives:

```text
["one", "two", "", "three"]
```

Remove the empty string:

```text
["one", "two", "three"]
```

So:

```text
ans = ["one", "two", "three"]
```

### Second Word

```text
"four.five".split(".")
```

gives:

```text
["four", "five"]
```

Add these to `ans`:

```text
ans = ["one", "two", "three", "four", "five"]
```

Final result:

```text
["one", "two", "three", "four", "five"]
```

---

## Key Takeaways

* Python's `split()` makes separator-based string processing simple.
* Consecutive separators can produce empty strings.
* Empty strings are removed before adding the results to the answer.
* `ans += y` combines the split words into the final list.
* The solution processes every input word and builds the result in a single overall traversal.
