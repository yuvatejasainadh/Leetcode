# 7. Reverse Integer

## Problem

Given a signed 32-bit integer `x`, return `x` with its digits reversed.

If reversing `x` causes the value to go outside the signed 32-bit integer range:

```text
[-2^31, 2^31 - 1]
```

return `0`.

### Examples

```text
Input:  x = 123
Output: 321
```

```text
Input:  x = -123
Output: -321
```

```text
Input:  x = 120
Output: 21
```

```text
Input:  x = 1534236469
Output: 0
```

---

## Intuition

To reverse an integer, we can repeatedly take its last digit and add it to the reversed number.

For example, consider:

```text
x = 123
```

We can extract the last digit using:

```cpp
x % 10
```

So:

```text
123 % 10 = 3
```

Then remove the last digit using:

```cpp
x /= 10
```

So:

```text
123 / 10 = 12
```

We can construct the reversed number using:

```cpp
rev = rev * 10 + digit;
```

The process becomes:

```text
x = 123

digit = 3
rev = 0 * 10 + 3 = 3

digit = 2
rev = 3 * 10 + 2 = 32

digit = 1
rev = 32 * 10 + 1 = 321
```

Therefore, the reversed number is:

```text
321
```

The same approach works for negative numbers because C++ preserves the sign when using `%` and `/` with integers.

---

## Approach

1. Initialize `rev = 0`.
2. Continue processing while `x != 0`.
3. Extract the last digit using `x % 10`.
4. Append the digit to `rev` using:

   ```cpp
   rev = rev * 10 + digit;
   ```
5. Remove the last digit from `x` using:

   ```cpp
   x /= 10;
   ```
6. After the loop, check whether `rev` is outside the signed 32-bit integer range.
7. Return `0` if an overflow occurs.
8. Otherwise, return the reversed number.

### Why `long long`?

The reversed value can temporarily exceed the range of an `int`.

The signed 32-bit integer range is:

```text
INT_MIN = -2147483648
INT_MAX =  2147483647
```

Therefore, `long long` is used for `rev` so that we can safely perform the reversal and then check whether the final result fits inside an `int`.

## Complexity

### Time Complexity

```text
O(log₁₀(|x|))
```

The number of iterations is equal to the number of digits in `x`.

For a 32-bit integer, there are at most 10 digits, so in practice this is effectively constant time.

### Space Complexity

```text
O(1)
```

Only a few variables are used, regardless of the size of the input.

---

## Code

```cpp
#include <climits>

class Solution {
public:
    int reverse(int x) {
        long long rev = 0;

        while (x != 0) {
            rev = rev * 10 + (x % 10);
            x /= 10;
        }

        return (rev > INT_MAX || rev < INT_MIN) ? 0 : rev;
    }
};
```

---

## Important Edge Cases

### 1. Negative Number

```text
Input:  -123
Output: -321
```

The sign is automatically preserved.

### 2. Trailing Zero

```text
Input:  120
Output: 21
```

The zero becomes a leading zero after reversal, which is ignored by integer representation.

### 3. Zero

```text
Input:  0
Output: 0
```

### 4. Positive Overflow

```text
Input:  1534236469
Output: 0
```

The reversed value is greater than `INT_MAX`, so we return `0`.

### 5. Negative Overflow

If the reversed value becomes smaller than `INT_MIN`, we also return `0`.

---

## Key Takeaways

* `% 10` extracts the last digit.
* `/ 10` removes the last digit.
* `rev * 10 + digit` builds the reversed number.
* `long long` prevents intermediate overflow during the calculation.
* Always check the final value against `INT_MIN` and `INT_MAX`.
* Return `0` when the reversed number does not fit in a signed 32-bit integer.
