# 2996. Smallest Missing Integer Greater Than Sequential Prefix Sum

## Intuition

We need to find the **sequential prefix** of the array starting from the first element.

A sequential prefix is a prefix where every consecutive element increases by exactly `1`.

For example:

```text
nums = [1, 2, 3, 2, 5]

Sequential prefix = [1, 2, 3]
```

The prefix stops as soon as the next element is not exactly one greater than the previous element.

After finding this prefix, we calculate its sum.

Then, starting from this sum, we look for the smallest integer that does **not** already exist in `nums`.

For example:

```text
nums = [1, 2, 3, 2, 5]

Sequential prefix = [1, 2, 3]
Prefix sum = 6

6 is not in nums
Answer = 6
```

---

## Approach

1. Start with the first element as the beginning of the sequential prefix.
2. Traverse the array from the second element.
3. Check whether the current element is exactly `1` greater than the previous element.
4. If it is, add the current element to the prefix sum.
5. If it is not, stop because the sequential prefix has ended.
6. Set `ans` equal to the sequential prefix sum.
7. While `ans` exists in `nums`, increment `ans`.
8. The first value that does not exist in `nums` is the answer.

### Example

Consider:

```text
nums = [3, 4, 5, 2, 1]
```

The sequential prefix is:

```text
[3, 4, 5]
```

Its sum is:

```text
3 + 4 + 5 = 12
```

Now check whether `12` exists in the array.

```text
12 ∉ nums
```

Therefore:

```text
Answer = 12
```

---

## Complexity

* Time complexity:

$$O(n^2)$$

The sequential prefix is found in `O(n)` time. The `while ans in nums` operation performs a linear search through the list, and in the worst case it can be repeated multiple times.

> In practice, the number of increments is small. We can also improve the membership check by using a set.

* Space complexity:

$$O(1)$$

The given implementation uses only a constant amount of extra space.

---

## Code

```python
class Solution:
    def missingInteger(self, nums: List[int]) -> int:
        sumP = nums[0]

        for i in range(1, len(nums)):
            if nums[i - 1] != nums[i] - 1:
                break

            sumP += nums[i]

        ans = sumP

        while ans in nums:
            ans += 1

        return ans
```

## Key Takeaways

* The **sequential prefix** always starts from `nums[0]`.
* Consecutive elements must differ by exactly `1`.
* Once the sequence breaks, we stop processing the prefix.
* Calculate the sum of the sequential prefix.
* Starting from that sum, find the smallest integer that is not present in `nums`.
* The given solution uses `O(1)` extra space.
