# Simple O(1) | Python | Math

## Intuition

We start with `numBottles` full bottles, so we can drink all of them initially.

After drinking a bottle, we get an empty bottle. Once we collect enough empty bottles, we can exchange them for a new full bottle.

Instead of simulating every exchange, we can directly calculate how many **additional bottles** we can obtain.

The key observation is:

```text
Every additional bottle consumed requires numExchange - 1 new empty bottles overall.
```

Therefore, the number of additional bottles is:

```python
(numBottles - 1) // (numExchange - 1)
```

Adding the bottles we initially had gives the final answer.

---

## Approach

1. Start with `numBottles` bottles, so initially we can drink:

   ```text
   numBottles
   ```

   bottles.
2. Calculate the number of additional bottles obtained through exchanges:

   ```python
   (numBottles - 1) // (numExchange - 1)
   ```
3. Add both values:

   ```python
   numBottles + (numBottles - 1) // (numExchange - 1)
   ```
4. Return the result.

This avoids simulating each individual exchange.

---

## Example

Consider:

```text
numBottles = 9
numExchange = 3
```

Initially, we can drink:

```text
9 bottles
```

After drinking them, we have `9` empty bottles.

We can exchange:

```text
9 → 3 full bottles
3 → 1 full bottle
```

So we can drink `4` additional bottles.

Therefore:

```text
9 + 4 = 13
```

Output:

```text
13
```

Using the formula:

```text
9 + (9 - 1) // (3 - 1)
= 9 + 8 // 2
= 9 + 4
= 13
```

## Complexity

* Time complexity:

$$O(1)$$

The solution performs only a fixed number of arithmetic operations.

* Space complexity:

$$O(1)$$

Only constant extra space is used.

---

## Code

```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        return numBottles + (numBottles - 1) // (numExchange - 1)
```

## Dry Run

Consider:

```text
numBottles = 15
numExchange = 4
```

Initial bottles:

```text
15
```

Additional bottles:

```text
(15 - 1) // (4 - 1)
= 14 // 3
= 4
```

Total:

```text
15 + 4 = 19
```

So the answer is:

```text
19
```

## Key Takeaways

* Drink all initially available bottles.
* Each consumed bottle provides an empty bottle.
* Bottle exchanges can be calculated directly using integer division.
* The formula avoids unnecessary simulation.
* The solution runs in constant time and space.
