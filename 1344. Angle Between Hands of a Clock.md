# Simple O(1) | Python | Math

## Intuition

A clock has two hands:

* **Minute hand:** moves `6°` for every minute.
* **Hour hand:** moves `0.5°` for every minute.

We can calculate the position of both hands from `12 o'clock`, find their absolute difference, and then choose the smaller angle between the two possible angles.

For example, at `3:30`:

```text
Hour hand   = 105°
Minute hand = 180°
Difference  = 75°
```

So the smaller angle is `75°`.

---

## Approach

### 1. Calculate the Hour Hand Position

The hour hand moves:

```text
30° per hour
```

and:

```text
0.5° per minute
```

Instead of calculating these separately, we can convert the hour into total minutes:

```python
((hour % 12) * 60 + minutes)
```

Then multiply by `0.5`:

```python
h = ((hour % 12) * 60 + minutes) * 0.5
```

The `% 12` handles both `12-hour` and `24-hour` representations.

### 2. Calculate the Minute Hand Position

The minute hand moves `6°` per minute:

```python
m = minutes * 6
```

### 3. Find the Difference

```python
an = abs(h - m)
```

There are two possible angles between the hands:

```text
an
360 - an
```

We need the smaller one:

```python
min(360 - an, an)
```

---

## Example

Consider:

```text
hour = 3
minutes = 30
```

### Hour Hand

```text
((3 × 60) + 30) × 0.5
= 210 × 0.5
= 105°
```

### Minute Hand

```text
30 × 6 = 180°
```

### Difference

```text
|105 - 180| = 75°
```

The other angle is:

```text
360 - 75 = 285°
```

Therefore:

```text
min(75, 285) = 75°
```

---

## Complexity

* Time complexity:

$$O(1)$$

Only a fixed number of arithmetic operations are performed.

* Space complexity:

$$O(1)$$

Only a few variables are used.

---

## Code

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        h = ((hour % 12) * 60 + minutes) * 0.5
        m = minutes * 6

        an = abs(h - m)

        return min(360 - an, an)
```

### Minute Hand

```text
30 × 6 = 180°
```

### Difference

```text
|15 - 180| = 165°
```

Other angle:

```text
360 - 165 = 195°
```

Smaller angle:

```text
165°
```

```text
165.0
```

## Key Takeaways

* The minute hand moves `6°` per minute.
* The hour hand moves `0.5°` per minute.
* The hour hand also moves continuously as the minutes pass.
* Use `hour % 12` to handle `12` correctly.
* The smaller angle is `min(angle, 360 - angle)`.
* The solution runs in constant time and space.
