# Simple O(n) | Python | String Prefix

## Intuition

A string `x` is a **prefix** of `s` if `s` starts with `x`.

Python provides the built-in `startswith()` method, which directly checks whether a string begins with another string.

So, for every word in `words`, we simply check:

```python
s.startswith(x)
```

If it returns `True`, we increment the count.

---

## Approach

1. Initialize `ans = 0`.
2. Iterate through every word `x` in `words`.
3. Check whether `x` is a prefix of `s` using:

   ```python
   s.startswith(x)
   ```
4. If it is a prefix, increment `ans`.
5. Return `ans`.

For example:

```text
words = ["a", "app", "ap", "apple"]
s = "apple"
```

All four words are prefixes of `"apple"`:

```text
"a"
"app"
"ap"
"apple"
```

Therefore, the answer is `4`.

---

## Example

Consider:

```text
words = ["a", "b", "c", "ab"]
s = "abc"
```

Check each word:

```text
"a"  → prefix → Yes
"b"  → prefix → No
"c"  → prefix → No
"ab" → prefix → Yes
```

Therefore:

```text
Output = 2
```

---

## Complexity

* Time complexity:

$$O(n \cdot m)$$

where `n` is the number of words and `m` is the length of the strings being compared.

Each `startswith()` operation may take time proportional to the length of the word.

* Space complexity:

$$O(1)$$

Only a constant amount of extra space is used.

---

## Code

```python
class Solution:
    def countPrefixes(self, words: List[str], s: str) -> int:
        ans = 0

        for x in words:
            if s.startswith(x):
                ans += 1

        return ans
```

## Dry Run

Consider:

```text

s = "apple"
```

| Word       | Prefix of `s`? | Count |
| ---------- | -------------- | ----: |
| `"a"`      | Yes            |     1 |
| `"ap"`     | Yes            |     2 |
| `"app"`    | Yes            |     3 |
| `"banana"` | No             |     3 |

Final answer:

```text
3
```

---

## Key Takeaways

* A prefix must occur at the **beginning** of the string.
* `startswith()` provides a simple way to check prefixes.
* Iterate through all words and count the ones that match.
* The solution uses constant extra space.
