# Simple O(n) | Python | Array

## Intuition

We need to distribute the elements of `nums` into two arrays, `ar1` and `ar2`.

The first element goes into `ar1` and the second element goes into `ar2`.

For every remaining element, compare the **last elements** of both arrays:

* If `ar1[-1] > ar2[-1]`, add the current element to `ar1`.
* Otherwise, add it to `ar2`.

Finally, concatenate both arrays and return the result.

---

## Approach

1. Create two empty arrays:

   ```python
   ar1 = []
   ar2 = []
   ```
2. Add the first element of `nums` to `ar1`.
3. Add the second element of `nums` to `ar2`.
4. Starting from index `2`, process every remaining element.
5. Compare the last elements of `ar1` and `ar2`.
6. Append the current element to the array whose last element is larger.
7. Return:

   ```python
   ar1 + ar2
   ```

---

## Example

Consider:

```text
nums = [2, 1, 3, 4, 5]
```

Initially:

```text
ar1 = [2]
ar2 = [1]
```

### Process `3`

```text
2 > 1
```

So:

```text
ar1 = [2, 3]
ar2 = [1]
```

### Process `4`

Compare:

```text
3 > 1
```

So:

```text
ar1 = [2, 3, 4]
ar2 = [1]
```

### Process `5`

Compare:

```text
4 > 1
```

So:

```text
ar1 = [2, 3, 4, 5]
ar2 = [1]
```

Finally:

```text
ar1 + ar2
= [2, 3, 4, 5, 1]
```

---

## Complexity

* Time complexity:

$$O(n)$$

Each element is processed exactly once.

* Space complexity:

$$O(n)$$

The two arrays together contain all elements of `nums`.

---

## Code

```python
class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        ar1 = []
        ar2 = []

        ar1.append(nums[0])
        ar2.append(nums[1])

        for i in range(2, len(nums)):
            if ar1[-1] > ar2[-1]:
                ar1.append(nums[i])
            else:
                ar2.append(nums[i])

        return ar1 + ar2
```

## Dry Run

For:

```text
nums = [5, 4, 3, 8]
```

Start:

```text
ar1 = [5]
ar2 = [4]
```

Process `3`:

```text
5 > 4
```

```text
ar1 = [5, 3]
ar2 = [4]
```

Process `8`:

```text
3 > 4 → False
```

So `8` goes to `ar2`:

```text
ar1 = [5, 3]
ar2 = [4, 8]
```

Final result:

```text
[5, 3, 4, 8]
```

---

## Key Takeaways

* Maintain two separate arrays.
* The first two elements initialize the arrays.
* Each remaining element is assigned based on the comparison of the two last elements.
* Concatenate the arrays at the end.
* The algorithm processes the input in a single pass.
