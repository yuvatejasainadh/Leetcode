# Simple O(n) | Python | Bit Manipulation

## Intuition

The encoded array is created using the XOR operation between consecutive elements of the original array.

For two consecutive values:

```text
encoded[i] = arr[i] XOR arr[i + 1]
```

We are given the first value `arr[0]`, so we can reconstruct every next value using the XOR property:

```text
a XOR b = c
```

implies:

```text
b = a XOR c
```

Therefore:

```python
ans[i + 1] = encoded[i] ^ ans[i]
```

---

## Approach

1. Create the result array and put `first` as the first element.
2. Iterate through every value in `encoded`.
3. The previous decoded value is `ans[-1]`.
4. XOR it with the current encoded value:

   ```python
   encoded[i] ^ ans[-1]
   ```
5. Append the result to `ans`.
6. Return the decoded array.

---

## Example

Consider:

```text
encoded = [1, 2, 3]
first = 1
```

Start with:

```text
ans = [1]
```

### First value

```text
1 XOR 1 = 0
```

```text
ans = [1, 0]
```

### Second value

```text
2 XOR 0 = 2
```

```text
ans = [1, 0, 2]
```

### Third value

```text
3 XOR 2 = 1
```

```text
ans = [1, 0, 2, 1]
```

Therefore:

```text
Output = [1, 0, 2, 1]
```

---

## Complexity

* Time complexity:

$$O(n)$$

We iterate through the `encoded` array once.

* Space complexity:

$$O(n)$$

The decoded array contains `n + 1` elements.

---

## Code

```python
class Solution:
    def decode(self, encoded: List[int], first: int) -> List[int]:
        ans = []
        ans.append(first)

        for x in encoded:
            ans.append(x ^ ans[-1])

        return ans
```

## Dry Run

Consider:

```text
encoded = [6, 2, 7, 3]
first = 4
```

Start:

```text
ans = [4]
```

Process each encoded value:

```text
6 XOR 4 = 2
```

```text
ans = [4, 2]
```

Next:

```text
2 XOR 2 = 0
```

```text
ans = [4, 2, 0]
```

Next:

```text
7 XOR 0 = 7
```

```text
ans = [4, 2, 0, 7]
```

Next:

```text
3 XOR 7 = 4
```

Final result:

```text
ans = [4, 2, 0, 7, 4]
```

---

## Key Takeaways

* XOR is reversible because:

  ```text
  a XOR b XOR a = b
  ```
* The first element is already given.
* Each next element can be recovered from the previous decoded element and the current encoded value.
* Only one pass through the array is required.
