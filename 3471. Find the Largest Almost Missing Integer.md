# Simple O(nk) | Python | Hash Set

## Intuition

We need to find the **largest integer that appears in exactly one subarray of length `k`**.

We can examine every possible subarray of size `k`. For each subarray, using a `set` ensures that if a number appears multiple times within the same subarray, it is counted only once.

Then, after processing all subarrays, we choose the largest number whose subarray count is exactly `1`.

---

## Approach

1. Initialize a frequency dictionary `cnt`.
2. Generate every subarray of length `k`.
3. Convert each subarray into a set:

   ```python
   set(nums[i:i+k])
   ```

   This removes duplicates within the same subarray.
4. Increment the count of every unique number found in that subarray.
5. Iterate through the frequency dictionary.
6. If a number appears in exactly one subarray, update the maximum answer.
7. Return `-1` if no such number exists.

---

## Example

Consider:

```text
nums = [3, 5, 2, 6]
k = 2
```

The subarrays are:

```text
[3, 5]
[5, 2]
[2, 6]
```

Count how many subarrays contain each number:

```text
3 → 1
5 → 2
2 → 2
6 → 1
```

Numbers appearing in exactly one subarray:

```text
3, 6
```

The largest is:

```text
6
```

So the answer is:

```text
6
```

---

## Complexity

* Time complexity:

$$O(nk)$$

There are `n - k + 1` subarrays, and creating each set from a subarray of size `k` takes `O(k)` time.

* Space complexity:

$$O(n)$$

The frequency dictionary can store up to `n` distinct values, while each temporary set uses up to `O(k)` space.

---

## Code

```python id="c4m8wz"
class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        ans = -1
        cnt = defaultdict(int)
        n = len(nums)

        for i in range(n - k + 1):
            unq = set(nums[i:i + k])

            for x in unq:
                cnt[x] += 1

        for x, y in cnt.items():
            if y == 1:
                ans = max(ans, x)

        return ans
```

## Key Takeaways

* Generate every contiguous subarray of size `k`.
* Use a `set` so duplicate occurrences within the same subarray are counted only once.
* Track how many different subarrays contain each number.
* Select the largest number whose count is exactly `1`.
* Return `-1` when no valid number exists.
