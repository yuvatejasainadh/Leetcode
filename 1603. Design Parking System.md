# Simple O(1) | Python | Simulation

## Intuition

The parking system has three types of parking spaces:

* `1` → Big
* `2` → Medium
* `3` → Small

We can store the available spaces in a list:

```python
sp = [big, medium, small]
```

Since `carType` starts from `1`, we can access the corresponding parking space using:

```python
self.sp[carType - 1]
```

Whenever a car arrives:

* If there are no spaces left, return `False`.
* Otherwise, decrease the available space by `1` and return `True`.

---

## Approach

1. Store the available parking spaces in `self.sp`.
2. Initialize:

   ```python
   self.sp[0] = big
   self.sp[1] = medium
   self.sp[2] = small
   ```
3. When `addCar(carType)` is called:

   * Convert `carType` to the corresponding list index using `carType - 1`.
   * Check whether the available space is `0`.
   * If it is `0`, return `False`.
   * Otherwise, decrease the available space by `1`.
   * Return `True`.

For example:

```text
big = 1
medium = 1
small = 0
```

The parking state is:

```text
[1, 1, 0]
```

If a small car arrives:

```text
carType = 3
```

There are no small spaces available, so:

```text
False
```

---

## Complexity

* Time complexity:

$$O(1)$$

Each `addCar()` operation performs only a constant number of operations.

* Space complexity:

$$O(1)$$

Only three parking-space counts are stored.

---

## Code

```python
class ParkingSystem:
    sp = [0] * 3

    def __init__(self, big: int, medium: int, small: int):
        self.sp[0], self.sp[1], self.sp[2] = big, medium, small

    def addCar(self, carType: int) -> bool:
        if self.sp[carType - 1] == 0:
            return False

        self.sp[carType - 1] -= 1
        return True
```


```text

sp = [0, 0, 0]
```


---

## Key Takeaways

* Use an array to store the remaining spaces for each car type.
* `carType - 1` maps the car type to the correct array index.
* Decrease the available space whenever a car is successfully parked.
* Return `False` when the corresponding parking space is full.
* Every operation takes constant time.
