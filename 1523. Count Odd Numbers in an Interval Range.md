# Simple O(1) | Python | Math

## Intuition

We need to count how many odd numbers exist in the inclusive range `[low, high]`.

Instead of checking every number individually, we can calculate how many odd numbers exist from `1` to `high` and subtract how many odd numbers exist before `low`.

The number of odd integers from `1` to `n` is:

```python
(n + 1) // 2
```

Therefore:

```python
(high + 1) // 2 - low // 2
```

directly gives the number of odd numbers in the range.

---

## Approach

1. Calculate the number of odd numbers from `1` to `high`:

   ```python
   (high + 1) // 2
   ```
2. Calculate the number of odd numbers from `1` to `low - 1`:

   ```python
   low // 2
   ```
3. Subtract the two values:

   ```python
   (high + 1) // 2 - low // 2
   ```
4. Return the result.

---

## Example

Consider:

```text
low = 3
high = 7
```

The numbers are:

```text
3, 4, 5, 6, 7
```

Odd numbers:

```text
3, 5, 7
```

So the answer is:

```text
3
```

Using the formula:

```text
(high + 1) // 2 - low // 2
= (7 + 1) // 2 - 3 // 2
= 8 // 2 - 1
= 4 - 1
= 3
```

---

## Complexity

* Time complexity:

$$O(1)$$

Only a few arithmetic operations are performed.

* Space complexity:

$$O(1)$$

No additional data structures are used.

---

## Code

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        return (high + 1) // 2 - low // 2
```

---

## Dry Run

Consider:

```text
low = 8
high = 10
```

Numbers:

```text
8, 9, 10
```

Only `9` is odd.

Using the formula:

```text
(10 + 1) // 2 - 8 // 2
= 11 // 2 - 4
= 5 - 4
= 1
```

Output:

```text
1
```

---

## Key Takeaways

* Avoid iterating through every number in the range.
* `(n + 1) // 2` gives the number of odd integers from `1` to `n`.
* Subtracting the count before `low` gives the answer for `[low, high]`.
* The solution runs in constant time and space.
