# Simple O(n²) | Python | String

## Intuition

We need to find the **first character that appears twice** while scanning the string from left to right.

For every character `x`, we check how many times it has appeared in the prefix of the string up to the current position:

```python
s[:i+1].count(x)
```

When this count becomes `2`, we know that `x` is the first character to appear twice.

For example:

```text
s = "abccbaacz"
```

Scanning from left to right:

```text
a → appears once
b → appears once
c → appears once
c → appears twice
```

So the answer is:

```text
"c"
```

---

## Approach

1. Traverse the string using `enumerate()`.
2. For every character `x` at index `i`, consider the prefix:

   ```python
   s[:i+1]
   ```
3. Count how many times `x` appears in that prefix.
4. If the count becomes `2`, return `x`.
5. If no character appears twice, return `"-1"`.

The important part is:

```python
if s[:i+1].count(x) == 2:
    return x
```

Because we scan from left to right, the first character satisfying this condition is the first repeated character.

---

## Example

Consider:

```text
s = "abccbaacz"
```

### Step-by-step

```text
i = 0 → a → "a".count("a") = 1
i = 1 → b → "ab".count("b") = 1
i = 2 → c → "abc".count("c") = 1
i = 3 → c → "abcc".count("c") = 2
```

At index `3`, `c` appears for the second time.

Therefore:

```text
Output = "c"
```

---

## Complexity

* Time complexity:

$$O(n^2)$$

For every character, `s[:i+1]` creates a new substring and `.count(x)` scans that substring.

In the worst case, this results in quadratic time.

* Space complexity:

$$O(n)$$

The slicing operation `s[:i+1]` creates temporary strings whose size can be up to `n`.

---

## Code

```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        for i, x in enumerate(s):
            if s[:i + 1].count(x) == 2:
                return x

        return "-1"
```

## Dry Run

### Input

```text
s = "abcdd"
```

| Index | Character | Prefix    | Count | Action     |
| ----: | :-------: | :-------- | ----: | ---------- |
|     0 |    `a`    | `"a"`     |     1 | Continue   |
|     1 |    `b`    | `"ab"`    |     1 | Continue   |
|     2 |    `c`    | `"abc"`   |     1 | Continue   |
|     3 |    `d`    | `"abcd"`  |     1 | Continue   |
|     4 |    `d`    | `"abcdd"` |     2 | Return `d` |

Final answer:

```text
"d"
```

---

## Key Takeaways

* Scan the string from left to right.
* Check the frequency of the current character in the prefix.
* The first character whose frequency reaches `2` is the answer.
* The implementation is simple but uses `O(n²)` time.
* A `set` can optimize this solution to `O(n)` time.
