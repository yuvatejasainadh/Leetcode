# Simple O(n) | Python | String & ASCII

## Intuition

Each character in the words represents a digit based on its position in the alphabet:

```text
a → 0
b → 1
c → 2
...
z → 25
```

We can convert each word into a number by replacing every character with its corresponding value and concatenating those values.

For example:

```text
"acb"
```

becomes:

```text
a → 0
c → 2
b → 1
```

So:

```text
"acb" → 021 → 21
```

After converting all three words into numbers, we simply check:

```text
firstWord + secondWord == targetWord
```

---

## Approach

We create a helper function `cSum()` that converts a word into its numerical representation.

For every character `x`:

```python
ord(x) - ord('a')
```

gives its zero-based alphabet position.

For example:

```text
ord('c') - ord('a') = 2
```

We append this value to the result string:

```python
ans += str(ord(x) - ord('a'))
```

Finally, we convert the resulting string into an integer.

Then we calculate:

```python
cSum(firstWord) + cSum(secondWord)
```

and compare it with:

```python
cSum(targetWord)
```

If they are equal, return `True`; otherwise, return `False`.

---

## Example

Consider:

```text
firstWord = "acb"
secondWord = "cba"
targetWord = "cdb"
```

Convert the words:

```text
acb → 021 → 21
cba → 210 → 210
cdb → 231 → 231
```

Now:

```text
21 + 210 = 231
```

Therefore:

```text
True
```

---

## Complexity

* Time complexity:

$$O(n)$$

where `n` is the total number of characters across the three words.

Each character is processed once.

* Space complexity:

$$O(n)$$

The helper function creates a string representation of the numerical value for each word.

---

## Code

```python
class Solution:
    def cSum(self, s):
        ans = ""

        for x in s:
            ans += str(ord(x) - ord('a'))

        return int(ans)

    def isSumEqual(
        self,
        firstWord: str,
        secondWord: str,
        targetWord: str
    ) -> bool:
        return (
            self.cSum(firstWord)
            + self.cSum(secondWord)
            == self.cSum(targetWord)
        )
```

## Key Takeaways

* Each lowercase letter can be converted to its alphabet index using `ord()`.
* `ord(x) - ord('a')` maps `a` to `0`, `b` to `1`, and so on.
* The resulting digit strings can be converted into integers.
* Finally, compare the sum of the first two word values with the target value.
