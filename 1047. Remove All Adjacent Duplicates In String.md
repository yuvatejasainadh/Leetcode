# Simple O(n) | Python | Stack

## Intuition

Whenever two adjacent characters are the same, they should be removed.

We can simulate this process using a string `st` as a stack:

* If the current character is the same as the last character in `st`, remove the last character.
* Otherwise, add the current character to `st`.

This naturally handles repeated removals because after deleting a pair, the new last character can be compared with the next character.

For example:

```text
s = "abbaca"
```

Process:

```text
a → "a"
b → "ab"
b → "a"      # remove "bb"
a → ""       # remove "aa"
c → "c"
a → "ca"
```

Final result:

```text
"ca"
```

---

## Approach

1. Initialize an empty string `st`.
2. Traverse every character `x` in `s`.
3. If `st` is not empty and the current character matches the last character:

   ```python
   x == st[-1]
   ```

   remove the last character:

   ```python
   st = st[:-1]
   ```
4. Otherwise, append the current character:

   ```python
   st += x
   ```
5. Return `st`.

The variable `st` behaves like a **stack**, where the last character can be removed whenever a duplicate is found.

## Complexity

* Time complexity:

$$O(n^2)$$

The intended stack approach is `O(n)`, but this implementation uses string slicing:

```python
st = st[:-1]
```

and string concatenation:

```python
st += x
```

Both can create new strings, so the actual worst-case complexity of this implementation can be quadratic.

* Space complexity:

$$O(n)$$

The string `st` can contain up to `n` characters.

---

## Code

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        st = ""

        for x in s:
            if st != "" and x == st[-1]:
                st = st[:-1]
            else:
                st += x

        return st
```

---

## Key Takeaways

* Use the result string as a stack.
* Compare each character with the last character already stored.
* Remove both characters when they are equal.
* Otherwise, add the current character.
* The approach naturally handles cascading removals.
* A Python list can be used instead of a string to achieve an efficient `O(n)` implementation.
