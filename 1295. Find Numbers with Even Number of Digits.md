# Simple O(n) | Python | String

## Intuition

We need to count how many integers in `nums` contain an **even number of digits**.

A simple way is to convert each number into a string and use `len()` to determine the number of digits.

For example:

```text
12 → 2 digits → Even
345 → 3 digits → Odd
6789 → 4 digits → Even
```

Whenever the number of digits is even, we increment the answer.

---

## Approach

1. Initialize `ans = 0`.
2. Iterate through every number `x` in `nums`.
3. Convert `x` into a string:

   ```python
   str(x)
   ```
4. Find its number of digits using:

   ```python
   len(str(x))
   ```
5. If the number of digits is even, increment `ans`.
6. Return `ans`.

The condition used is:

```python
len(str(x)) % 2 == 0
```

---

## Example

Consider:

```text
nums = [12, 345, 2, 6, 7896]
```

Check each number:

```text
12   → 2 digits → Count
345  → 3 digits → Ignore
2    → 1 digit  → Ignore
6    → 1 digit  → Ignore
7896 → 4 digits → Count
```

Therefore:

```text
Output = 2
```

---

## Complexity

* Time complexity:

$$O(n \cdot d)$$

where `n` is the number of elements and `d` is the number of digits in each number.

Converting each number to a string takes time proportional to its number of digits.

Under the given constraints, this is effectively:

$$O(n)$$

* Space complexity:

$$O(d)$$

because converting a number to a string temporarily requires space proportional to its number of digits.

Under the given constraints, this is effectively:

$$O(1)$$

---

## Code

```python
class Solution:
    def findNumbers(self, nums: List[int]) -> int:
        ans = 0

        for x in nums:
            if len(str(x)) % 2 == 0:
                ans += 1

        return ans
```

## Key Takeaways

* Convert each number to a string to easily determine its digit count.
* Use `% 2` to check whether the number of digits is even.
* Increment the counter for every valid number.
* The solution requires only a single traversal of the array.
