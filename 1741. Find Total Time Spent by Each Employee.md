# Simple O(n) | MySQL | GROUP BY

## Intuition

Each employee can have multiple work records on the same day.

We need to calculate the **total working time** for each employee on each day.

For every record:

```text
Working Time = out_time - in_time
```

So, we can group all records by:

* `event_day`
* `emp_id`

and then use `SUM()` to calculate the total working time.

---

## Approach

1. Select `event_day` and rename it as `day`.
2. Select the employee ID using `emp_id`.
3. Calculate the total working time using:

   ```sql
   SUM(out_time - in_time)
   ```
4. Group the records by both employee and day:

   ```sql
   GROUP BY emp_id, event_day
   ```

This combines all working sessions belonging to the same employee on the same day.

---

## Example

Suppose the table contains:

| event_day  | emp_id | in_time | out_time |
| ---------- | -----: | ------: | -------: |
| 2024-01-01 |      1 |      10 |       20 |
| 2024-01-01 |      1 |      30 |       50 |
| 2024-01-01 |      2 |      15 |       25 |

For employee `1`:

```text
(20 - 10) + (50 - 30)
= 10 + 20
= 30
```

The result would be:

| day        | emp_id | total_time |
| ---------- | -----: | ---------: |
| 2024-01-01 |      1 |         30 |
| 2024-01-01 |      2 |         10 |

---

## Complexity

* Time complexity:

$$O(n)$$

The database processes the rows and performs grouping and aggregation.

* Space complexity:

$$O(n)$$

The grouping operation may require additional space internally for the grouped results.

---

## Code

```mysql
# Write your MySQL query statement below

SELECT 
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM employees
GROUP BY emp_id, event_day;
```

---

## Key Takeaways

* Use `SUM()` to calculate total working time.
* Use `GROUP BY` when aggregation is required for each employee and day.
* Grouping by both `emp_id` and `event_day` ensures each employee-day combination is handled separately.
* `AS` can be used to rename columns in the output.
