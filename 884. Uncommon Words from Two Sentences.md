# Simple O(n) | Python | Hash Map

## Intuition

We need to find the words that appear **exactly once** across both sentences.

A simple way is to combine all words from `s1` and `s2` into one list and count the frequency of each word.

If a word occurs only once, it is an **uncommon word**.

For example:

```text
s1 = "this apple is sweet"
s2 = "this apple is sour"
```

Combined words:

```text
["this", "apple", "is", "sweet", "this", "apple", "is", "sour"]
```

Their frequencies are:

```text
this  → 2
apple → 2
is    → 2
sweet → 1
sour  → 1
```

Therefore, the uncommon words are:

```text
["sweet", "sour"]
```

---

## Approach

1. Split both sentences into individual words using `split()`.
2. Combine the two lists:

   ```python
   words = s1.split() + s2.split()
   ```
3. Use `Counter` to count the frequency of every word.
4. Iterate through the frequency map.
5. Add a word to the answer if its count is exactly `1`.
6. Return the resulting list.

The `Counter` from Python's `collections` module acts as a frequency map.

---

## Complexity

* Time complexity:

$$O(n)$$

where `n` is the total number of characters/words processed across both sentences.

Splitting the sentences and counting the words each take linear time.

* Space complexity:

$$O(n)$$

The combined word list, frequency map, and result can require space proportional to the number of words.

---

## Code

```python
from collections import Counter

class Solution:
    def uncommonFromSentences(self, s1: str, s2: str) -> List[str]:
        words = s1.split() + s2.split()
        cnt = Counter(words)

        return [word for word, count in cnt.items() if count == 1]
```

## Dry Run

Consider:

```text
s1 = "this apple is sweet"
s2 = "this apple is sour"
```

### Step 1: Split Sentences

```python
s1.split()
```

gives:

```text
["this", "apple", "is", "sweet"]
```

and:

```python
s2.split()
```

gives:

```text
["this", "apple", "is", "sour"]
```

### Step 2: Combine

```text
["this", "apple", "is", "sweet",
 "this", "apple", "is", "sour"]
```

### Step 3: Count Frequencies

```text
this  → 2
apple → 2
is    → 2
sweet → 1
sour  → 1
```

### Step 4: Select Words With Count `1`

```text
["sweet", "sour"]
```

---

## Key Takeaways

* `split()` converts sentences into lists of words.
* `Counter` efficiently stores word frequencies.
* A word is uncommon if its frequency across both sentences is exactly `1`.
* List comprehension makes filtering the unique words concise.
