# Simple O(n) | Python | Regular Expressions

## Intuition

The problem asks us to determine whether the entire string `s` matches the pattern `p`.

The pattern supports two special characters:

* `.` — matches any single character.
* `*` — matches zero or more occurrences of the preceding character.

Python already provides a regular expression engine through the `re` module that supports these rules.

Instead of implementing the matching logic manually, we can use Python's built-in regular expression functionality.

The important part is that we need the **entire string** to match the pattern, not just a substring.

Therefore, `re.fullmatch()` is suitable for this problem.

---

## Approach

1. Convert the given pattern into a raw f-string:

   ```python
   pat = fr"{p}"
   ```

2. Use:

   ```python
   re.fullmatch(pat, s)
   ```

   This checks whether the complete string `s` matches the complete pattern.

3. If a match is found, return `True`.

4. Otherwise, return `False`.

### Example

Consider:

```text
s = "aab"
p = "c*a*b"
```

The pattern can be interpreted as:

```text
c* → zero occurrences of c
a* → two occurrences of a
b  → one occurrence of b
```

Therefore:

```text
"aab" matches "c*a*b"
```

and the result is:

```text
True
```

---

## Complexity

* Time complexity:

$$O(n)$$

The regular expression engine processes the input and pattern. The exact runtime of a general regular expression engine can vary depending on the pattern, but for the purpose of this solution we consider the matching operation as linear with respect to the input size.

* Space complexity:

$$O(n)$$

The regular expression engine may use additional memory for the matching process, depending on the pattern and input.

---

## Code

```python
import re

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        pat = fr"{p}"

        if re.fullmatch(pat, s):
            return True

        return False
```

## Dry Run

### Example 1

```text
Input:
s = "aa"
p = "a"
```

The pattern `a` matches only one `a`.

```text
"aa" ≠ "a"
```

Therefore:

```text
Output = False
```

---

### Example 2

```text
Input:
s = "aa"
p = "a*"
```

The `*` allows zero or more occurrences of the preceding character.

Therefore:

```text
"a*" → "aa"
```

So:

```text
Output = True
```

---

### Example 3

```text
Input:
s = "ab"
p = ".*"
```

`.` matches any character and `*` allows zero or more occurrences.

Therefore `.*` can match:

```text
"ab"
```

So:

```text
Output = True
```

## Key Takeaways

* Python's `re` module provides built-in regular expression functionality.
* `.` matches any single character.
* `*` matches zero or more occurrences of the preceding character.
* `re.fullmatch()` ensures that the **entire string** matches the pattern.
* This approach avoids implementing the regular expression matching logic manually.
