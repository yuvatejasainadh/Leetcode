# Simple O(n) | Python | Prefix & Suffix Products

## Intuition

For every index `i`, we need the product of all elements **except** `nums[i]`.

Instead of calculating the product separately for every index, we can split the required product into two parts:

* Product of all elements to the **left** of `i`.
* Product of all elements to the **right** of `i`.

For example:

```text
nums = [1, 2, 3, 4]
```

For `i = 2`:

```text
Left product  = 1 × 2 = 2
Right product = 4
Answer        = 2 × 4 = 8
```

We store these two products in two arrays:

* `pr` → prefix products
* `su` → suffix products

Then:

```text
answer[i] = pr[i] × su[i]
```

---

## Approach

We use three passes through the array.

### 1. Build Prefix Products

`pr[i]` stores the product of all elements before index `i`.

```python
pr[i] = pr[i - 1] * nums[i - 1]
```

For:

```text
nums = [1, 2, 3, 4]
```

we get:

```text
pr = [1, 1, 2, 6]
```

### 2. Build Suffix Products

`su[i]` stores the product of all elements after index `i`.

We traverse from right to left:

```python
su[i] = su[i + 1] * nums[i + 1]
```

For:

```text
nums = [1, 2, 3, 4]
```

we get:

```text
su = [24, 12, 4, 1]
```

### 3. Calculate the Answer

For every index:

```python
ans.append(pr[i] * su[i])
```

Therefore:

```text
pr = [1, 1, 2, 6]
su = [24, 12, 4, 1]

ans = [24, 12, 8, 6]
```

---

## Complexity

* Time complexity:

$$O(n)$$

We traverse the array three times, and each traversal takes `O(n)` time.

Therefore:

$$O(n) + O(n) + O(n) = O(n)$$

* Space complexity:

$$O(n)$$

Two auxiliary arrays `pr` and `su` are created, each of size `n`. The output array also contains `n` elements.

---

## Code

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        pr = [1] * len(nums)
        su = [1] * len(nums)

        for i in range(1, len(nums)):
            pr[i] = pr[i - 1] * nums[i - 1]

        for i in range(len(nums) - 2, -1, -1):
            su[i] = su[i + 1] * nums[i + 1]

        ans = []

        for i in range(len(nums)):
            ans.append(pr[i] * su[i])

        return ans
```

## Dry Run

Consider:

```text
nums = [1, 2, 3, 4]
```

### Prefix Array

```text
pr = [1, 1, 2, 6]
```

Explanation:

```text
pr[0] = 1
pr[1] = 1
pr[2] = 1 × 2 = 2
pr[3] = 1 × 2 × 3 = 6
```

### Suffix Array

```text
su = [24, 12, 4, 1]
```

Explanation:

```text
su[3] = 1
su[2] = 4
su[1] = 3 × 4 = 12
su[0] = 2 × 3 × 4 = 24
```

### Final Answer

```text
ans[0] = 1 × 24 = 24
ans[1] = 1 × 12 = 12
ans[2] = 2 × 4  = 8
ans[3] = 6 × 1  = 6
```

Therefore:

```text
[24, 12, 8, 6]
```

---

## Key Takeaways

* Split the product into **prefix** and **suffix** products.
* `pr[i]` contains the product of elements before `i`.
* `su[i]` contains the product of elements after `i`.
* Multiplying `pr[i]` and `su[i]` gives the product of every element except `nums[i]`.
* The solution does not use division, so it also works correctly when the array contains zeroes.
* The current implementation uses `O(n)` extra space.
* It can be optimized to `O(1)` extra space by storing prefix products directly in the answer array.
