# Simple O(n) | Python | Linked List & Binary

## Intuition

The linked list represents a binary number, where each node contains either `0` or `1`.

For example:

```text
1 → 0 → 1
```

represents:

```text
101₂
```

which is equal to:

```text
5
```

We can traverse the linked list, build the binary number as a string, and then use Python's `int()` with base `2` to convert it into a decimal number.

---

## Approach

1. Initialize an empty string `ans`.
2. Start traversing the linked list from `head`.
3. Append each node's value to `ans`.
4. Move to the next node.
5. Once the entire linked list has been traversed, convert the binary string into an integer using:

   ```python
   int(ans, 2)
   ```
6. If the linked list is empty, return `0`.

For example:

```text
1 → 0 → 1 → 0
```

is converted to:

```text
"1010"
```

Then:

```python
int("1010", 2)
```

returns:

```text
10
```

---

## Example

Consider:

```text
head = 1 → 0 → 1
```

### Traverse the Linked List

```text
1 → ans = "1"
0 → ans = "10"
1 → ans = "101"
```

Now:

```text
ans = "101"
```

Convert from binary:

```text
int("101", 2) = 5
```

Therefore:

```text
Output = 5
```

---

## Complexity

* Time complexity:

$$O(n)$$

We traverse every node once. The binary string conversion also takes linear time with respect to the number of bits.

* Space complexity:

$$O(n)$$

The binary representation is stored as a string of length `n`.

---

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def getDecimalValue(self, head: Optional[ListNode]) -> int:
        ans = ""
        temp = head

        while temp:
            ans += str(temp.val)
            temp = temp.next

        return int(ans, 2) if ans else 0
```

## Dry Run

Consider:

```text
head = 1 → 0 → 0 → 1
```

| Node | `ans`    |

| `0`  | `"10"`   |
| `0`  | `"100"`  |
| `1`  | `"1001"` |

Now convert:

```text
int("1001", 2)
```

Binary calculation:

```text
1 × 2³ + 0 × 2² + 0 × 2¹ + 1 × 2⁰
= 8 + 1
= 9
```

Therefore:

```text
Output = 9
```

---

## Key Takeaways

* Each linked-list node represents one binary digit.
* Traverse the linked list from left to right.
* Store the binary representation as a string.
* `int(ans, 2)` converts the binary string into decimal.
* The solution requires one traversal of the linked list.
