# Simple O((m+n) log(m+n)) | Python | Sorting

## Intuition

The first `m` elements of `nums1` and all `n` elements of `nums2` are already sorted.

`nums1` also has `n` extra positions at the end, which are reserved for the elements of `nums2`.

A simple approach is to first copy all elements of `nums2` into those empty positions in `nums1`.

After that, `nums1` contains all the elements from both arrays, so we can simply sort it.

For example:

```text
nums1 = [1, 2, 3, 0, 0, 0]
nums2 = [2, 5, 6]
```

After copying:

```text
nums1 = [1, 2, 3, 2, 5, 6]
```

After sorting:

```text
nums1 = [1, 2, 2, 3, 5, 6]
```

---

## Approach

1. Iterate through all elements of `nums2`.
2. Place each element into the unused portion of `nums1`, starting from index `m`.
3. After copying all elements, sort the entire `nums1` array.
4. Since the problem requires modifying `nums1` in-place, no result needs to be returned.

The assignment:

```python
nums1[i + m] = nums2[i]
```

places each element of `nums2` after the existing `m` elements of `nums1`.

---

## Example

Consider:

```text
nums1 = [1, 2, 3, 0, 0, 0]
m = 3

nums2 = [2, 5, 6]
n = 3
```

### Step 1: Copy `nums2`

```text
nums1[3] = 2
nums1[4] = 5
nums1[5] = 6
```

Now:

```text
nums1 = [1, 2, 3, 2, 5, 6]
```

### Step 2: Sort

```text
nums1 = [1, 2, 2, 3, 5, 6]
```

Final result:

```text
[1, 2, 2, 3, 5, 6]
```

---

## Complexity

* Time complexity:

$$O(n + (m+n)\log(m+n))$$

Copying the `n` elements from `nums2` takes:

$$O(n)$$

Sorting the combined array of `m+n` elements takes:

$$O((m+n)\log(m+n))$$

Therefore, the overall complexity is:

$$O((m+n)\log(m+n))$$

* Space complexity:

$$O(1)$$

The solution modifies `nums1` in-place and does not explicitly create another array.

---

## Code

```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """

        for i in range(n):
            nums1[i + m] = nums2[i]

        nums1.sort()
```

## Edge Cases

### `nums2` is Empty

```text
nums1 = [1]
m = 1

nums2 = []
n = 0
```

Nothing needs to be copied or sorted.

Result:

```text
[1]
```

### `nums1` Has No Initial Elements

```text
nums1 = [0]
m = 0

nums2 = [1]
n = 1
```

Copy:

```text
nums1 = [1]
```

Result:

```text
[1]
```

### Duplicate Values

```text
nums1 = [1, 2, 2, 0, 0]
nums2 = [2, 3]
```

After copying:

```text
[1, 2, 2, 2, 3]
```

The array is already sorted.

---

## Key Takeaways

* `nums1` already contains enough extra space for `nums2`.
* Copy `nums2` into the unused portion of `nums1`.
* Sort the resulting array.
* The solution is simple and easy to implement.
* The optimal two-pointer solution can achieve `O(m+n)` time without sorting.
