# O(log n) | Python | Digit Manipulation

## Intuition

We need to check whether `n` is divisible by the sum of its digits plus the product of its digits.

For a number `n`, calculate:

```text
sum = sum of all digits
product = product of all digits
```

Then check whether:

```text
n % (sum + product) == 0
```

If the remainder is `0`, `n` is divisible by `sum + product`.

---

## Approach

1. Convert `n` into a string and extract each digit.
2. Convert each digit back to an integer.
3. Maintain:

   * `s` → sum of digits
   * `p` → product of digits
4. For every digit:

   ```python
   s += x
   p *= x
   ```
5. Check whether `n` is divisible by `s + p`.
6. Return `True` if divisible, otherwise `False`.

---

## Example

Consider:

```text
n = 99
```

Digits:

```text
9, 9
```

Sum:

```text
9 + 9 = 18
```

Product:

```text
9 × 9 = 81
```

Therefore:

```text
sum + product = 18 + 81 = 99
```

Now:

```text
99 % 99 = 0
```

So the answer is:

```text
True
```

---

## Complexity

* Time complexity:

$$O(\log n)$$

The number of digits in `n` is proportional to `log(n)`.

* Space complexity:

$$O(\log n)$$

The digits are stored in a list after converting the number to a string.

---

## Code

```python
class Solution:
    def checkDivisibility(self, n: int) -> bool:
        s = 0
        p = 1

        nums = list(map(int, str(n)))

        for x in nums:
            s += x
            p *= x

        return True if n % (s + p) == 0 else False
```

## Dry Run

For:

```text
n = 123
```

Digits:

```text
1, 2, 3
```

Calculate the sum:

```text
1 + 2 + 3 = 6
```

Calculate the product:

```text
1 × 2 × 3 = 6
```

Therefore:

```text
sum + product = 6 + 6 = 12
```

Check:

```text
123 % 12 = 3
```

Since the remainder is not `0`:

```text
False
```

---

## Key Takeaways

* Extract the digits of the number.
* Calculate their sum and product.
* Add the two values.
* Check whether the original number is divisible by the result.
* The number of digits determines the running time.
