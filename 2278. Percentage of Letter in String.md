# Simple O(n) | Python | String

## Intuition

We need to find the percentage of characters in `s` that are equal to the given `letter`.

Python's `count()` method directly gives us the number of occurrences of `letter`.

The percentage can then be calculated as:

```text
(number of occurrences × 100) / length of string
```

Since the problem asks for the **integer percentage**, we use floor division `//`.

---

## Approach

1. Count how many times `letter` appears in `s`:

   ```python
   s.count(letter)
   ```
2. Multiply the count by `100`.
3. Divide by the length of `s` using `//` to obtain the integer percentage.
4. Return the result.

The formula is:

```text
percentage = (count(letter) × 100) // len(s)
```

---

## Example

Consider:

```text
s = "foobar"
letter = "o"
```

The letter `"o"` appears `2` times.

The length of the string is `6`.

Therefore:

```text
(2 × 100) // 6
= 200 // 6
= 33
```

So the answer is:

```text
33
```

---

## Complexity

* Time complexity:

$$O(n)$$

`s.count(letter)` scans the string, where `n` is the length of `s`.

* Space complexity:

$$O(1)$$

Only a constant amount of extra space is used.

---

## Code

```python
class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        return (s.count(letter) * 100 // len(s))
```

## Key Takeaways

* `str.count()` can directly count occurrences of a character.
* Multiply the count by `100` to calculate the percentage.
* Use `//` because the required result is an integer.
* The solution requires only one scan of the string.
