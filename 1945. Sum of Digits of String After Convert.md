# Simple O(n + k log n) | Python | String & Math

## Intuition

Each lowercase letter is first converted into its **alphabet position**:

```text
a → 1
b → 2
c → 3
...
z → 26
```

We concatenate these values to form a number.

For example:

```text
s = "zbax"
```

becomes:

```text
z → 26
b → 2
a → 1
x → 24
```

So:

```text
"zbax" → "262124"
```

Then we repeatedly calculate the **sum of the digits** `k` times.

---

## Approach

### Step 1: Convert Characters to Numbers

For every character `x`, calculate:

```python
ord(x) - ord('a') + 1
```

This converts:

```text
a → 1
b → 2
...
z → 26
```

The values are concatenated into the string `ans`.

For example:

```text
"leetcode"
```

is converted to:

```text
12 5 5 20 3 15 4 5
```

giving:

```text
"12552031545"
```

### Step 2: Perform Digit Sum

Repeat the digit-sum operation `k` times:

```python
ans = str(sum(list(map(int, ans))))
```

For example:

```text
"12552031545"
```

becomes:

```text
1 + 2 + 5 + 5 + 2 + 0 + 3 + 1 + 5 + 4 + 5
= 33
```

If another iteration is required:

```text
3 + 3 = 6
```

Finally, convert the resulting string back to an integer.

---

## Example

Consider:

```text
s = "iiii"
k = 1
```

Convert each character:

```text
i → 9
```

Therefore:

```text
"iiii" → "9999"
```

Digit sum:

```text
9 + 9 + 9 + 9 = 36
```

So:

```text
Output = 36
```

---

## Complexity

* Time complexity:

$$O(n + k \log n)$$

Converting the original string takes `O(n)` time.

The digit-sum operation is repeated `k` times, and the number of digits decreases rapidly after each transformation.

* Space complexity:

$$O(n)$$

The string representation of the transformed number can require space proportional to the size of the converted input.

---

## Code

```python
class Solution:
    def getLucky(self, s: str, k: int) -> int:
        ans = ""

        for x in s:
            ans += str(ord(x) - ord('a') + 1)

        for _ in range(k):
            ans = str(sum(list(map(int, ans))))

        return int(ans)
```

## Key Takeaways

* Convert each character into its alphabet position using `ord()`.
* Concatenate the resulting values.
* Repeatedly calculate the sum of the digits `k` times.
* The value quickly becomes small after each digit-sum operation.
* The solution uses string manipulation along with basic arithmetic.
