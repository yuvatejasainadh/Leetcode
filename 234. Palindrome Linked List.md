# Simple O(n) | Python | Linked List & String

## Intuition

A linked list is a palindrome if its values read the same **forward and backward**.

For example:

```text
1 → 2 → 2 → 1
```

Reading it forward and backward gives:

```text
1221
1221
```

So it is a palindrome.

We can traverse the linked list, store all node values in a string, and then compare the string with its reverse.

---

## Approach

1. Initialize an empty string `ans`.
2. Traverse the linked list using a temporary pointer.
3. Append each node's value to `ans`.
4. After traversing the complete linked list, reverse the string using:

   ```python
   ans[::-1]
   ```
5. Compare the original string with its reversed version.
6. If they are equal, return `True`; otherwise, return `False`.

The main condition is:

```python
ans == ans[::-1]
```

---

## Example

Consider:

```text
head = 1 → 2 → 2 → 1
```

After traversing the linked list:

```text
ans = "1221"
```

Reverse:

```text
ans[::-1] = "1221"
```

Since both are equal:

```text
Output = True
```

---

## Complexity

* Time complexity:

$$O(n)$$

We traverse the linked list once and then reverse the resulting string.

* Space complexity:

$$O(n)$$

The values of all `n` nodes are stored in the string `ans`.

---

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        ans = ""
        temp = head

        while temp:
            ans += str(temp.val)
            temp = temp.next

        return ans == ans[::-1]
```

---

## Dry Run

Consider:

```text
head = 1 → 2 → 3 → 2 → 1
```

### Traverse the Linked List

```text
1 → ans = "1"
2 → ans = "12"
3 → ans = "123"
2 → ans = "1232"
1 → ans = "12321"
```

Now reverse the string:

```text
"12321"[::-1] = "12321"
```

Comparison:

```text
"12321" == "12321"
```

Therefore:

```text
Output = True
```

---

## Non-Palindrome Example

Consider:

```text
head = 1 → 2 → 3
```

The string becomes:

```text
"123"
```

Its reverse is:

```text
"321"
```

Since:

```text
"123" != "321"
```

the result is:

```text
False
```

---

## Key Takeaways

* Convert the linked-list values into a sequence.
* A palindrome is equal to its reverse.
* Python slicing `[::-1]` provides a simple way to reverse the sequence.
* The solution requires one traversal of the linked list.
* This approach uses extra space to store the node values.
