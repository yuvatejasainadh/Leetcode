# 3. Longest Substring Without Repeating Characters

## Intuition

We need to find the length of the longest substring that contains no repeated characters.

A **sliding window** is a natural way to solve this problem.

We maintain a window from index `i` to index `j` such that all characters inside the window are unique.

As we move `j` forward:

* If `s[j]` is not already in the window, we can safely add it.
* If `s[j]` is already present, we remove characters from the left side of the window until the duplicate character is removed.
* At every step, we calculate the current window length and update the maximum length.

For example:

```text
s = "abcabcbb"
```

We first get:

```text
"abc"
```

When we encounter the second `a`, we move the left pointer forward until the duplicate is removed.

The longest substring without repeating characters is:

```text
"abc"
```

So the answer is:

```text
3
```

---

## Approach

We use two pointers, `i` and `j`, to represent the current sliding window.

A `set<char>` is used to store the characters currently present in the window.

1. Initialize:

   * `i = 0` as the left pointer.
   * `maxLen = 0` to store the maximum length.
   * An empty set to store characters in the current window.

2. Iterate through the string using `j`.

3. If `s[j]` is already present in the set:

   * Remove `s[i]` from the set.
   * Increment `i`.
   * Continue until `s[j]` is no longer present.

4. Insert `s[j]` into the set.

5. Calculate the current window length:

```cpp
j - i + 1
```

6. Update `maxLen`.

7. Return `maxLen` after processing the entire string.

### Example

For:

```text
s = "abcabcbb"
```

The sliding window changes approximately as follows:

```text
""
"a"
"ab"
"abc"
"bc"
"bca"
"cab"
"abc"
"cb"
"b"
```

The longest valid window is:

```text
"abc"
```

Therefore:

```text
Answer = 3
```

---

## Complexity

* Time complexity:

$$O(n \log n)$$

The string is traversed using the sliding window. Each character can be inserted into and removed from the `set`.

Since `std::set` operations take `O(log n)`, the overall complexity is `O(n log n)`.

* Space complexity:

$$O(n)$$

In the worst case, the set can contain all characters of the string.

## Code

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        set<char> st;

        int i = 0;
        int len = s.size();

        if (len == 0)
            return 0;

        int maxLen = INT_MIN;

        for (int j = 0; j < len; j++) {

            while (st.find(s[j]) != st.end()) {
                st.erase(s[i]);
                i++;
            }

            st.insert(s[j]);

            maxLen = max(maxLen, j - i + 1);
        }

        return maxLen;
    }
};
```

## Edge Cases

### Empty String

```text
Input: ""
Output: 0
```

### All Characters Are Unique

```text
Input: "abcdef"
Output: 6
```

### All Characters Are the Same

```text
Input: "aaaaa"
Output: 1
```

### String Contains Spaces

Spaces are also characters, so they are handled normally.

```text
Input: "a b"
Output: 3
```

---

## Key Takeaways

* Use a **sliding window** to maintain the current substring.
* Use a `set` to ensure all characters in the window are unique.
* Move the right pointer forward to expand the window.
* Move the left pointer forward whenever a duplicate is found.
* Update the maximum window size after every iteration.
* Each character enters and leaves the sliding window at most once.
