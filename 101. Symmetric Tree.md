# O(n) | Python | Recursion & Binary Tree

## Intuition

A binary tree is symmetric if its left and right subtrees are **mirror images** of each other.

For two nodes to be mirrors:

* Their values must be equal.
* The left child of the first node must match the right child of the second node.
* The right child of the first node must match the left child of the second node.

For example:

```text
        1
       / \
      2   2
     / \ / \
    3  4 4  3
```

The two subtrees are mirror images, so the tree is symmetric.

---

## Approach

We use a recursive helper function `same(a, b)` to check whether two subtrees are mirrors.

### Base Cases

If both nodes are `None`:

```python
if a is None and b is None:
    return True
```

They are mirror-compatible.

If only one node is `None`:

```python
if a is None or b is None:
    return False
```

The structures are different, so they cannot be mirrors.

### Compare Values

If the node values are different:

```python
if a.val != b.val:
    return False
```

the tree is not symmetric.

### Check Mirror Subtrees

We recursively compare:

```python
r1 = self.same(a.left, b.right)
r2 = self.same(b.left, a.right)
```

Notice that the comparison is **crossed**:

```text
a.left  ↔ b.right
a.right ↔ b.left
```

Both comparisons must be true.

---

## Example

Consider:

```text
        1
       / \
      2   2
     / \ / \
    3  4 4  3
```

First:

```text
2 == 2
```

Then compare:

```text
left subtree of first 2  ↔ right subtree of second 2
```

```text
3 ↔ 3
```

and:

```text
4 ↔ 4
```

Both sides match, so the tree is symmetric.

---

## Complexity

* Time complexity:

$$O(n)$$

Each node is visited once during the recursive comparison.

* Space complexity:

$$O(h)$$

where `h` is the height of the tree, due to the recursive call stack.

For a balanced tree:

$$O(\log n)$$

For a completely skewed tree:

$$O(n)$$

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def same(self, a, b):
        if a is None and b is None:
            return True

        if a is None or b is None:
            return False

        if a.val != b.val:
            return False

        r1 = self.same(a.left, b.right)
        r2 = self.same(b.left, a.right)

        return r1 and r2

    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if root is None:
            return True

        return self.same(root.left, root.right)
```

## Dry Run

Consider:

```text
        1
       / \
      2   2
     /     \
    3       3
```

Call:

```python
same(root.left, root.right)
```

Compare:

```text
2 == 2
```

Then:

```text
left of first 2  → 3
right of second 2 → 3
```

So:

```text
3 == 3 → True
```

Other sides:

```text
None ↔ None → True
```

Therefore:

```text
True AND True = True
```

Final result:

```text
True
```

---

## Key Takeaways

* Symmetry means the left and right subtrees are mirror images.
* Compare node values first.
* Compare children **crosswise**:

  ```text
  left ↔ right
  right ↔ left
  ```
* Recursion naturally handles the entire tree.
* An empty tree is considered symmetric.
