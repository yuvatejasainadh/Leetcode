# Simple O(log n) | Python | Bit Manipulation

## Intuition

The key observation is that the bitwise AND of all numbers in a range keeps only the **common leading bits** of `left` and `right`.

Any bit that changes within the range will eventually become `0` when performing AND across all numbers.

For example:

```text
left  = 5  = 101
right = 7  = 111
```

The numbers are:

```text
5 = 101
6 = 110
7 = 111
```

Their bitwise AND is:

```text
101
110
111
---
100
```

So the answer is:

```text
4
```

Therefore, instead of checking every number in the range, we can find the **common prefix of the binary representations** of `left` and `right`.

---

## Approach

We repeatedly right-shift both `left` and `right` until they become equal.

Each right shift removes the least significant bit.

While:

```python
left < right
```

we perform:

```python
left >>= 1
right >>= 1
```

At the same time, we count how many shifts were performed.

Once `left == right`, we have found the common binary prefix.

Finally, we shift the common prefix back to its original position:

```python
left << shifts
```

### Example

Consider:

```text
left = 5
right = 7
```

Binary:

```text
5 = 101
7 = 111
```

First shift:

```text
101 >> 1 = 10
111 >> 1 = 11
```

Second shift:

```text
10 >> 1 = 1
11 >> 1 = 1
```

Now both values are equal:

```text
1
```

We performed `2` shifts.

Shift the common prefix back:

```text
1 << 2 = 100
```

Therefore:

```text
Answer = 4
```

---

## Complexity

* Time complexity:

$$O(\log n)$$

Each iteration removes one binary digit from `left` and `right`. Therefore, the number of iterations is proportional to the number of bits in the numbers.

* Space complexity:

$$O(1)$$

Only a constant number of variables are used.

---

## Code

```python
class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        shifts = 0

        while left < right:
            left >>= 1
            right >>= 1
            shifts += 1

        return left << shifts
```

```text

```

```text

```

---

## Key Takeaways

* The AND of a range keeps only the bits common to every number.
* The common bits are represented by the common binary prefix of `left` and `right`.
* Right-shifting removes bits that are not common.
* Once both numbers become equal, shifting the result back gives the answer.
* This avoids iterating through every number in the range.
