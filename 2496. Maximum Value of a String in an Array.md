# Simple O(n) | Python | String

## Intuition

Each string in `strs` can represent either:

* A **number**, if it contains only digits.
* A **string**, if it contains at least one letter.

The value of each element is:

* For a numeric string → its integer value.
* For a non-numeric string → its length.

We simply calculate the value of every string and keep track of the maximum.

---

## Approach

1. Initialize `ans = 0`.
2. Iterate through every string `x` in `strs`.
3. Use `x.isdigit()` to determine whether the string contains only digits.
4. If it is numeric:

   ```python
   int(x)
   ```

   converts it into its integer value.
5. Otherwise, use:

   ```python
   len(x)
   ```

   as its value.
6. Update the maximum using `max()`.
7. Return `ans`.

---

## Example

Consider:

```text
strs = ["alic3", "bob", "3", "4", "00000"]
```

Their values are:

```text
"alic3" → length = 5
"bob"   → length = 3
"3"     → value = 3
"4"     → value = 4
"00000" → value = 0
```

Therefore:

```text
Maximum = 5
```

---

## Complexity

* Time complexity:

$$O(n \cdot m)$$

where `n` is the number of strings and `m` is the maximum length of a string.

Each string may need to be scanned to check whether it contains only digits.

* Space complexity:

$$O(1)$$

Only a constant amount of extra space is used.

---

## Code

```python
class Solution:
    def maximumValue(self, strs: List[str]) -> int:
        ans = 0

        for x in strs:
            if x.isdigit():
                ans = max(ans, int(x))
            else:
                ans = max(ans, len(x))

        return ans
```

## Key Takeaways

* `isdigit()` identifies strings containing only digits.
* Numeric strings are converted using `int()`.
* Non-numeric strings use their length as the value.
* `max()` keeps track of the largest value.
* The solution requires only constant extra space.
