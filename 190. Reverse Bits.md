# Simple O(1) | Python | Bit Manipulation

## Intuition

The problem asks us to reverse the bits of a **32-bit unsigned integer**.

For example:

```text
Input:
n = 00000010100101000001111010011100

Output:
00111001011110000010100101000000
```

Python provides built-in functions to convert an integer into its binary representation.

We can:

1. Convert `n` to binary using `bin(n)`.
2. Remove the `0b` prefix.
3. Pad the binary representation to exactly **32 bits** using `zfill(32)`.
4. Reverse the string using slicing `[::-1]`.
5. Convert the reversed binary string back into an integer using `int(..., 2)`.

---

## Approach

The solution can be broken into three simple steps.

### 1. Convert to Binary

```python
bin(n)[2:]
```

`bin(n)` returns a string beginning with `0b`.

For example:

```text
bin(10) = "0b1010"
```

Removing the first two characters gives:

```text
"1010"
```

### 2. Make It 32 Bits

A 32-bit integer must contain exactly 32 binary digits.

We use:

```python
zfill(32)
```

For example:

```text
"1010".zfill(32)
```

becomes:

```text
00000000000000000000000000001010
```

### 3. Reverse and Convert

We reverse the binary string:

```python
[::-1]
```

Then convert it back to an integer:

```python
int(binary_string, 2)
```

So the complete operation is:

```python
int(bin(n)[2:].zfill(32)[::-1], 2)
```

---

## Complexity

* Time complexity:

$$O(1)$$

The input is always exactly 32 bits, so we perform a constant number of operations over 32 bits.

* Space complexity:

$$O(1)$$

The binary representation contains only 32 bits, so the additional space used is constant.

---

## Code

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        return int(bin(n)[2:].zfill(32)[::-1], 2)
```

## Dry Run

Consider:

```text
n = 10
```

Binary representation:

```text
10 = 1010
```

After padding to 32 bits:

```text
00000000000000000000000000001010
```

After reversing:

```text
01010000000000000000000000000000
```

Converting this binary value back to decimal gives:

```text
1342177280
```

Therefore:

```text
Output = 1342177280
```

---

## Key Takeaways

* `bin(n)` converts an integer to binary.
* `[2:]` removes the `0b` prefix.
* `zfill(32)` ensures exactly 32 bits.
* `[::-1]` reverses the bit sequence.
* `int(..., 2)` converts the binary string back to an integer.
* Since the problem always works with 32-bit integers, the solution runs in constant time and space.
