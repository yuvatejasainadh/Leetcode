# O(n) | Python | Hash Set & Greedy

## Intuition

Each row in the cinema can accommodate at most **2 families** of 4 people.

The possible groups of four seats are:

```text
Left:   2, 3, 4, 5
Middle: 4, 5, 6, 7
Right:  6, 7, 8, 9
```

We can initially assume every row can accommodate two families:

```python
ans = n * 2
```

Then, for every row that contains reserved seats, we check which groups are still available.

The important observation is that **only rows containing reserved seats need to be checked**. Every other row can automatically accommodate two families.

---

## Approach

1. Store the reserved seats for each row using a dictionary of sets:

   ```python
   reserved_rows = defaultdict(set)
   ```
2. Initially assume every row can fit two families:

   ```python
   ans = n * 2
   ```
3. For each row containing reserved seats, check three possible blocks:

   * Left block: `(2, 3, 4, 5)`
   * Right block: `(6, 7, 8, 9)`
   * Middle block: `(4, 5, 6, 7)`
4. If both left and right blocks are available, the row still accommodates two families, so no change is needed.
5. If at least one valid block is available, the row can accommodate one family, so subtract `1`.
6. Otherwise, no family can be placed in that row, so subtract `2`.
7. Return the final answer.

---

## Example

Consider:

```text
n = 3
reservedSeats = [[1, 2], [1, 3], [1, 8]]
```

Initially:

```text
3 × 2 = 6
```

families can potentially be seated.

For row `1`:

```text
Left  = [2, 3, 4, 5] → unavailable
Right = [6, 7, 8, 9] → unavailable
Middle = [4, 5, 6, 7] → available
```

So row `1` can accommodate one family.

The other two rows have no reservations and can accommodate two families each.

Therefore:

```text
1 + 2 + 2 = 5
```

families can be seated.

---

## Complexity

* Time complexity:

$$O(n + r)$$

where `n` is the number of rows and `r` is the number of reserved seats.

We process each reserved seat once and then check only the rows that contain reservations.

Since only a constant number of seats are checked for each affected row, the additional work is constant per row.

* Space complexity:

$$O(r)$$

The dictionary stores the reserved seats.

---

## Code

```python
class Solution:
    def maxNumberOfFamilies(
        self,
        n: int,
        reservedSeats: list[list[int]]
    ) -> int:

        reserved_rows = defaultdict(set)

        for row, seat in reservedSeats:
            reserved_rows[row].add(seat)

        ans = n * 2

        for row, seats in reserved_rows.items():
            left_avail = not any(
                s in seats for s in (2, 3, 4, 5)
            )

            right_avail = not any(
                s in seats for s in (6, 7, 8, 9)
            )

            mid_avail = not any(
                s in seats for s in (4, 5, 6, 7)
            )

            if left_avail and right_avail:
                continue
            elif left_avail or right_avail or mid_avail:
                ans -= 1
            else:
                ans -= 2

        return ans
```

## Dry Run

Consider:

```text
n = 2
reservedSeats = [
    [1, 2],
    [1, 3],
    [1, 8]
]
```

Initially:

```text
ans = 2 × 2 = 4
```

For row `1`:

```text
Reserved = {2, 3, 8}
```

### Left Block

```text
2, 3, 4, 5
```

Seat `2` or `3` is reserved:

```text
left_avail = False
```

### Right Block

```text
6, 7, 8, 9
```

Seat `8` is reserved:

```text
right_avail = False
```

### Middle Block

```text
4, 5, 6, 7
```

No seats are reserved:

```text
mid_avail = True
```

Therefore:

```text
ans -= 1
```

So:

```text
ans = 3
```

Row `2` has no reserved seats and can accommodate two families.

Final answer:

```text
3
```

## Key Takeaways

* Every empty row can accommodate **2 families**.
* Only rows with reserved seats need special handling.
* There are only three possible 4-seat blocks that matter.
* A row can accommodate:

  * **2 families** if both left and right blocks are available.
  * **1 family** if at least one valid block is available.
  * **0 families** otherwise.
* Using sets makes reserved-seat lookups efficient.
