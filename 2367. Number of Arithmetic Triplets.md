# O(n³) | Python | Brute Force

## Intuition

An arithmetic triplet consists of three indices `i < j < k` such that:

```text
nums[j] - nums[i] = diff
nums[k] - nums[j] = diff
```

We can check every possible combination of three indices and count the combinations that satisfy these conditions.

---

## Approach

1. Iterate through every possible first index `i`.
2. Iterate through every possible second index `j` after `i`.
3. Iterate through every possible third index `k` after `j`.
4. Check whether:

   ```python
   nums[j] - nums[i] == diff
   ```

   and

   ```python
   nums[k] - nums[j] == diff
   ```
5. If both conditions are satisfied, store `(i, j, k)` in a set.
6. Return the size of the set.

Since each combination of indices is already unique, the set is not strictly necessary, but it ensures that the stored triplets are unique.

---

## Example

Consider:

```text
nums = [0, 1, 4, 6, 7, 10]
diff = 3
```

One valid triplet is:

```text
[1, 4, 7]
```

because:

```text
4 - 1 = 3
7 - 4 = 3
```

Another valid triplet is:

```text
[4, 7, 10]
```

because:

```text
7 - 4 = 3
10 - 7 = 3
```

Therefore, the answer is:

```text
2
```

---

## Complexity

* Time complexity:

$$O(n^3)$$

Three nested loops examine every possible combination of three indices.

* Space complexity:

$$O(n^3)$$

In the worst case, the set can contain up to `O(n³)` triplets.

---

## Code

```python
class Solution:
    def arithmeticTriplets(self, nums: List[int], diff: int) -> int:
        ans = set()
        n = len(nums)

        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[j] - nums[i] == diff and nums[k] - nums[j] == diff:
                        ans.add((i, j, k))

        return len(ans)
```

## Dry Run

For:

```text
nums = [0, 1, 4, 6, 7, 10]
diff = 3
```

Consider:

```text
i = 1 → nums[i] = 1
j = 2 → nums[j] = 4
k = 4 → nums[k] = 7
```

Check:

```text
4 - 1 = 3
7 - 4 = 3
```

Both conditions are true, so:

```text
(1, 2, 4)
```

is added to the set.

Another valid combination:

```text
(2, 4, 5)
```

because:

```text
7 - 4 = 3
10 - 7 = 3
```

Thus:

```text
answer = 2
```

---

## Key Takeaways

* Use three indices `i < j < k`.
* Both consecutive differences must equal `diff`.
* The brute-force approach checks every possible triplet.
* The given solution directly follows the definition of an arithmetic triplet.
