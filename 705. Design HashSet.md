# Simple O(n) | Python | Array

## Intuition

A HashSet normally stores each key only once and supports three basic operations:

* `add(key)` → insert the key.
* `remove(key)` → remove the key.
* `contains(key)` → check whether the key exists.

In this implementation, two lists are used:

* `self.s` stores the actual keys.
* `self.c` stores a count associated with each key.

For example:

```text
s = [2, 5, 8]
c = [1, 1, 1]
```

The index of a key in `self.s` corresponds to its count in `self.c`.

If a key already exists, its count is increased. If it doesn't exist, it is added to the lists.

---

## Approach

### `__init__()`

Initialize two empty lists:

```python
self.s = []
self.c = []
```

`self.s` stores the keys, while `self.c` stores their corresponding counts.

### `add(key)`

Check whether the key already exists.

If it exists:

```python
self.c[self.s.index(key)] += 1
```

Otherwise, add the key and initialize its count:

```python
self.s.append(key)
self.c.append(1)
```

### `remove(key)`

If the key exists, find its index and remove both the key and its corresponding count:

```python
self.c.pop(self.s.index(key))
self.s.remove(key)
```

### `contains(key)`

Check whether the key exists in `self.s`:

```python
key in self.s
```

Return `True` if found and `False` otherwise.

## Complexity

* Time complexity:

$$O(n)$$

The list operations such as `in`, `.index()`, `.remove()`, and `.pop()` may require scanning the list.

Here, `n` is the number of stored keys.

* Space complexity:

$$O(n)$$

The implementation stores the keys and their associated counts in two lists.

---

## Code

```python
class MyHashSet:

    def __init__(self):
        self.s = []
        self.c = []

    def add(self, key: int) -> None:
        if key in self.s:
            self.c[self.s.index(key)] += 1
        else:
            self.s.append(key)
            self.c.append(1)

    def remove(self, key: int) -> None:
        if key in self.s:
            self.c.pop(self.s.index(key))
            self.s.remove(key)

    def contains(self, key: int) -> bool:
        if key in self.s:
            return True
        return False

```

## Key Takeaways

* `self.s` acts as the storage for keys.
* `self.c` keeps a corresponding count for each key.
* `.index()` is used to locate a key.
* List-based searching makes operations linear in the number of stored keys.
* A real hash-set implementation would use hashing to achieve average **O(1)** operations.
