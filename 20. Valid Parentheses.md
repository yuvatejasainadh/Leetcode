# Simple O(n²) | Python | Stack

## Intuition

The brackets are valid only when every closing bracket matches the **most recently opened bracket**.

For example:

```text
"([])"
```

The order of opening brackets is:

```text
(
[
```

So `]` must close `[` first, followed by `)` closing `(`.

This follows the **Last In, First Out (LIFO)** principle, which is exactly how a stack works.

In the given solution, the variable `ans` is used as a stack:

* Opening brackets are added to `ans`.
* When a closing bracket is encountered, we check the last character of `ans`.
* If it is the corresponding opening bracket, we remove it.
* Otherwise, the string is invalid.
* At the end, the stack must be empty for the parentheses to be valid.

---

## Approach

1. Initialize an empty string `ans` to act as a stack.
2. Traverse every character in the string.
3. When an opening bracket is encountered:

   * Add it to `ans`.
4. When a closing bracket is encountered:

   * Check whether the stack is empty.
   * If it is empty, the closing bracket has nothing to match, so return `False`.
   * Otherwise, compare the closing bracket with the last opening bracket in `ans`.
5. If the brackets match:

   * Remove the last character from `ans`.
6. If they do not match:

   * Return `False`.
7. After processing the entire string:

   * If `ans` is empty, all brackets were matched.
   * Otherwise, some opening brackets remain unmatched.

### Example

Consider:

```text
s = "([])"
```

Processing the characters:

```text
( → ans = "("
[ → ans = "(["
] → remove "[" → ans = "("
) → remove "(" → ans = ""
```

The stack is empty at the end, so:

```text
Output = True
```

---

## Complexity

* Time complexity:

$$O(n^2)$$

The algorithm traverses the string once, but removing the last character using:

```python
ans = ans[:-1]
```

creates a new string, which takes `O(n)` time in the worst case.

Therefore, the worst-case complexity of the given implementation is:

$$O(n^2)$$

* Space complexity:

$$O(n)$$

The `ans` string can contain up to `n` opening brackets.

---

## Code

```python
class Solution:
    def isValid(self, s: str) -> bool:
        ans = ""

        if not s:
            return True

        for x in s:
            if x == ')' and ans:
                if ans[-1] == '(':
                    ans = ans[:-1]
                else:
                    return False

            elif x == ']' and ans:
                if ans[-1] == '[':
                    ans = ans[:-1]
                else:
                    return False

            elif x == '}' and ans:
                if ans[-1] == '{':
                    ans = ans[:-1]
                else:
                    return False

            else:
                ans += x

        return ans == ""
```

## Key Takeaways

* Valid parentheses follow a **Last In, First Out (LIFO)** order.
* A stack is the natural data structure for this problem.
* Every closing bracket must match the most recently opened bracket.
* The stack must be empty after processing the complete string.
* The given implementation uses a Python string as a stack.

> **Optimization:** Using a Python `list` with `append()` and `pop()` would make the solution `O(n)` time because `ans = ans[:-1]` creates a new string each time.
