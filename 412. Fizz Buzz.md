# Simple O(n) | Python | Math

## Intuition

For every number from `1` to `n`, we need to determine whether it is divisible by `3`, `5`, both, or neither.

The conditions are:

* Divisible by both `3` and `5` → `"FizzBuzz"`
* Divisible only by `3` → `"Fizz"`
* Divisible only by `5` → `"Buzz"`
* Otherwise → the number itself as a string

Since a number divisible by both `3` and `5` is also divisible by each individually, the **FizzBuzz condition must be checked first**.

---

## Approach

1. Create an empty list `ans`.
2. Iterate from `1` to `n`.
3. For each number:

   * If divisible by both `3` and `5`, append `"FizzBuzz"`.
   * Else if divisible by `3`, append `"Fizz"`.
   * Else if divisible by `5`, append `"Buzz"`.
   * Otherwise, convert the number to a string and append it.
4. Return `ans`.

For example, for:

```text
n = 15
```

the output is:

```text
["1", "2", "Fizz", "4", "Buzz", "Fizz",
 "7", "8", "Fizz", "Buzz", "11", "Fizz",
 "13", "14", "FizzBuzz"]
```

---

## Complexity

* Time complexity:

$$O(n)$$

We process every number from `1` to `n` exactly once.

* Space complexity:

$$O(n)$$

The result list contains `n` elements.

---

## Code

```python
class Solution:
    def fizzBuzz(self, n: int) -> List[str]:
        ans = []

        for i in range(1, n + 1):
            if i % 3 == 0 and i % 5 == 0:
                ans.append("FizzBuzz")
            elif i % 3 == 0:
                ans.append("Fizz")
            elif i % 5 == 0:
                ans.append("Buzz")
            else:
                ans.append(str(i))

        return ans
```

## Key Takeaways

* Use the modulo operator `%` to check divisibility.
* Check the combined condition `i % 3 == 0 and i % 5 == 0` first.
* Process each number exactly once.
* The solution is simple and runs in linear time.
