# Simple O(n) | Python | String

## Intuition

We need to count how many words in the given range both **start and end with a vowel**.

The vowels are:

```text
a, e, i, o, u
```

For every word between indices `left` and `right`, we only need to check:

* Whether its first character is a vowel.
* Whether its last character is a vowel.

If both conditions are true, we increment the answer.

---

## Approach

1. Store all vowels in a string:

   ```python
   v = "aeiou"
   ```
2. Traverse the words from `left` to `right`, including both boundaries.
3. For each word:

   ```python
   words[i][0]
   ```

   gives its first character.

   ```python
   words[i][-1]
   ```

   gives its last character.
4. If both characters are vowels, increment `ans`.
5. Return `ans`.

---

## Example

Consider:

```text
words = ["are", "amy", "u", "over", "the"]
left = 0
right = 3
```

Check each word:

```text
"are"  → a and e → vowel → count
"amy"  → a and y → not count
"u"    → u and u → vowel → count
"over" → o and r → not count
```

Therefore:

```text
Output = 2
```

---

## Complexity

* Time complexity:

$$O(n)$$

where `n = right - left + 1`.

We check each word in the specified range exactly once.

* Space complexity:

$$O(1)$$

Only a few variables are used, regardless of the number of words.

---

## Code

```python
class Solution:
    def vowelStrings(self, words: List[str], left: int, right: int) -> int:
        ans = 0
        v = "aeiou"

        for i in range(left, right + 1):
            if words[i][0] in v and words[i][-1] in v:
                ans += 1

        return ans
```

## Dry Run

Consider:

```text
words = ["aba", "bcb", "ece", "aa", "e"]
left = 0
right = 4
```

| Word  | First | Last | Valid? |
| ----- | ----- | ---- | ------ |
| `aba` | `a`   | `a`  | Yes    |
| `bcb` | `b`   | `b`  | No     |
| `ece` | `e`   | `e`  | Yes    |
| `aa`  | `a`   | `a`  | Yes    |
| `e`   | `e`   | `e`  | Yes    |

Total:

```text
4
```

---

## Key Takeaways

* Store the vowels in a lookup string.
* Only the first and last characters of each word matter.
* Iterate only through the requested `[left, right]` range.
* Increment the count when both characters are vowels.
* The solution runs in linear time with constant extra space.
